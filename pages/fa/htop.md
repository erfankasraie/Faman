# Introduction

`htop` نسخه‌ی تعاملی و رنگی دستور `top` است که وضعیت لحظه‌ای پردازش‌ها، مصرف CPU و حافظه را به‌صورت گرافیکی (در ترمینال) نشان می‌دهد و امکان مدیریت پردازش‌ها (کشتن، تغییر اولویت) را با کلیدهای میانبر یا موس فراهم می‌کند.

برای مبتدیان: اگر سیستم کند شده و می‌خواهید ببینید کدام برنامه منابع را می‌خورد، `htop` را اجرا کنید.

# Syntax

```
htop [OPTIONS]
```

# Options

| گزینه | توضیح |
|-------|--------|
| `-u USER` | فقط پردازش‌های یک کاربر خاص |
| `-p PID,PID` | فقط پردازش‌های مشخص‌شده با PID |
| `-d N` | فاصله به‌روزرسانی (به دهم ثانیه) |
| `-t` | نمایش درختی پردازش‌ها (parent/child) |
| `-C` | حالت بدون رنگ |

# Examples

```bash
# اجرای ساده
htop

# نمایش فقط پردازش‌های یک کاربر
htop -u ali

# نمایش درختی برای دیدن رابطه والد/فرزند
htop -t
```

کلیدهای مهم داخل htop:
- `F6` یا `>` / `<` : مرتب‌سازی بر اساس ستون
- `F9` : کشتن پردازش انتخاب‌شده (kill)
- `F5` : تغییر به نمای درختی
- `q` : خروج

# Common mistakes

- گیج‌شدن بین `%CPU` (که می‌تواند بالای ۱۰۰٪ باشد در سیستم چند‌هسته‌ای) و درصد واقعی مصرف.
- فراموش‌کردن اینکه برای کشتن پردازش سیستمی یا متعلق به کاربر دیگر نیاز به `sudo htop` است.

# Tips

- با زدن `/` می‌توانید داخل htop جستجو کنید.
- ستون‌های نمایش‌داده‌شده از طریق `F2` (Setup) کاملاً قابل شخصی‌سازی است.
- در بسیاری از توزیع‌ها باید جداگانه نصب شود: `apt install htop` یا `brew install htop`.

# Related commands

- `top` — نسخه پایه و همیشه‌موجود
- `ps` — لیست پردازش‌ها به‌صورت لحظه‌ای (غیرتعاملی)
- `kill` / `pkill` — کشتن پردازش
- `nice` / `renice` — تنظیم اولویت پردازش
