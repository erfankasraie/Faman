# Introduction

`rev` کاراکترهای هر خط را برعکس می‌کند (نه ترتیب خطوط را). برای معکوس‌کردن رشته یا برخی ترفندهای پردازش متن کاربرد دارد.

# Syntax

```
rev [FILE]
```

# Options

`rev` گزینه خاصی ندارد؛ فقط یک فایل (یا ورودی استاندارد) را می‌گیرد و هر خط را برعکس چاپ می‌کند.

# Examples

```bash
# برعکس‌کردن یک رشته ساده
echo "سلام" | rev

# برعکس‌کردن هر خط یک فایل
rev file.txt

# ترفند: پیداکردن آخرین فیلد یک خط با ترکیب rev و cut
echo "a:b:c:d" | rev | cut -d':' -f1 | rev
```

# Common mistakes

- اشتباه‌گرفتن `rev` (که ترتیب کاراکترها را برعکس می‌کند) با `tac` (که ترتیب خطوط را برعکس می‌کند).

# Tips

- ترکیب `rev` با `cut` روش رایجی برای گرفتن آخرین N فیلد یک خط CSV/جداشده بدون دانستن تعداد کل فیلدها است.

# Related commands

- `tac` — برعکس‌کردن ترتیب خطوط یک فایل
- `cut` — استخراج فیلد از یک خط
