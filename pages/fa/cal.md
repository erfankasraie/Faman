# Introduction

`cal` یک تقویم ساده در ترمینال نمایش می‌دهد؛ می‌تواند ماه جاری، یک ماه خاص، یا کل یک سال را نشان دهد.

# Syntax

```
cal [OPTIONS] [[MONTH] YEAR]
```

# Options

| گزینه | توضیح |
|-------|--------|
| `-y` | نمایش تمام تقویم سال جاری |
| `-3` | نمایش ماه قبل، جاری و بعد کنار هم |
| `-m` | شروع هفته از دوشنبه به‌جای یکشنبه |

# Examples

```bash
# تقویم ماه جاری
cal

# تقویم کل سال ۲۰۲۶
cal -y 2026

# نمایش سه ماه (قبل، جاری، بعد) کنار هم
cal -3

# تقویم یک ماه خاص از یک سال خاص
cal 3 2027
```

# Common mistakes

- انتظار داشتن تقویم شمسی (جلالی)؛ `cal` استاندارد فقط تقویم میلادی را نشان می‌دهد. برای تقویم شمسی باید از ابزارهای جداگانه‌ای مثل `jcal` استفاده کرد.

# Tips

- برای کار با تقویم فارسی/شمسی در لینوکس، بسته `jcal` (بخشی از `jalali-cal` یا مشابه) را جستجو و نصب کنید.
- `cal -3` برای برنامه‌ریزی کارهایی که به مرز ماه نزدیک است بسیار مفید است.

# Related commands

- `date` — نمایش و تنظیم تاریخ و زمان سیستم
- `timedatectl` — مدیریت کامل زمان و منطقه زمانی
