# Introduction

`stat` اطلاعات دقیق و کامل متادیتای یک فایل یا پوشه را نمایش می‌دهد: اندازه، مجوزها، مالک، و سه نوع زمان مختلف (دسترسی، تغییر محتوا، تغییر متادیتا) — اطلاعاتی بسیار جزئی‌تر از `ls -l`.

# Syntax

```
stat [OPTIONS] FILE...
```

# Options

| گزینه | توضیح |
|-------|--------|
| `-c FORMAT` | خروجی با قالب دلخواه (مفید برای اسکریپت) |
| `-f` | نمایش اطلاعات فایل‌سیستم به‌جای فایل |
| `-L` | دنبال‌کردن لینک نمادین |
| `--printf=FORMAT` | مثل `-c` ولی بدون خط جدید خودکار در انتها |

نمادهای رایج قالب:

| نماد | معنی |
|------|------|
| `%s` | اندازه بایت |
| `%U` | نام مالک |
| `%a` | مجوز اکتال (مثل ۶۴۴) |
| `%y` | زمان آخرین تغییر محتوا |
| `%n` | نام فایل |

# Examples

```bash
# نمایش کامل اطلاعات یک فایل
stat file.txt

# فقط اندازه فایل به بایت (برای اسکریپت)
stat -c %s file.txt

# فقط مجوز اکتال (برای مقایسه یا بازیابی بعدی)
stat -c %a file.txt

# بررسی زمان آخرین تغییر محتوا
stat -c %y file.txt

# اطلاعات فایل‌سیستمی که فایل روی آن است (نه خود فایل)
stat -f file.txt

# مقایسه اندازه دو فایل در اسکریپت
size1=$(stat -c %s file1)
size2=$(stat -c %s file2)
```

# Common mistakes

- گیج‌شدن بین سه نوع زمان: `atime` (آخرین دسترسی/خواندن)، `mtime` (آخرین تغییر محتوا) و `ctime` (آخرین تغییر متادیتا مثل مجوز)؛ این‌ها معانی متفاوتی دارند و `ls -l` پیش‌فرض فقط `mtime` را نشان می‌دهد.
- استفاده از `stat` بدون `-c`/`--format` در اسکریپت که خروجی طولانی و ناپایدار برای پارس‌کردن است؛ همیشه در اسکریپت‌ها از فرمت مشخص استفاده کنید.

# Tips

- برای backup یا مقایسه فایل‌ها بر اساس زمان تغییر: `stat -c %Y file.txt` (زمان mtime به‌صورت timestamp عددی، قابل مقایسه مستقیم).
- خروجی `stat -c %a` (مجوز اکتال) دقیقاً همان چیزی است که `chmod` نیاز دارد، پس برای «ذخیره و بازگرداندن مجوز فایل» بسیار مفید است.

# Related commands

- `ls -l` — نمایش خلاصه‌تر مجوز و اندازه
- `file` — تشخیص نوع فایل (نه متادیتا)
- `touch` — تغییر زمان دسترسی/تغییر یک فایل
- `chmod` — تغییر مجوز نمایش‌داده‌شده توسط stat
