# Introduction

`bc` یک ماشین‌حساب خط‌فرمانی با دقت دلخواه است که می‌تواند محاسبات اعشاری انجام دهد؛ کاری که پوسته bash به‌تنهایی (با `$(( ))`) قادر به انجامش نیست چون فقط اعداد صحیح را پشتیبانی می‌کند.

# Syntax

```
bc [OPTIONS] [FILE]
echo "EXPRESSION" | bc
```

# Options

| گزینه | توضیح |
|-------|--------|
| `-l` | فعال‌کردن کتابخانه ریاضی (توابعی مثل `sin`, `sqrt`) |

# Examples

```bash
# محاسبه ساده اعشاری (که bash خودش نمی‌تواند)
echo "10 / 3" | bc -l

# محاسبه با تعداد رقم اعشار مشخص
echo "scale=4; 22/7" | bc

# جذر یک عدد (نیاز به -l)
echo "sqrt(2)" | bc -l

# استفاده تعاملی
bc -l
# سپس می‌توانید مستقیم عبارت وارد کنید، مثلاً: 3^10

# استفاده در یک اسکریپت برای محاسبه درصد
percent=$(echo "scale=2; 45/200*100" | bc)
echo "$percent%"
```

# Common mistakes

- استفاده از `$(( ))` در bash برای محاسبات اعشاری که همیشه نتیجه صحیح (بدون اعشار) و گاهی غلط می‌دهد؛ برای اعشار باید از `bc` یا `awk` استفاده کرد.
- فراموش‌کردن `scale=N` که باعث می‌شود نتیجه تقسیم بدون رقم اعشار (و گاهی صفر) نمایش داده شود.

# Tips

- برای محاسبات سریع در اسکریپت، ترکیب `echo "expr" | bc -l` رایج‌ترین الگو است.
- به‌جای `bc` می‌توان از `awk 'BEGIN{print expr}'` هم برای محاسبات اعشاری استفاده کرد؛ هر دو رایج هستند.

# Related commands

- `expr` — محاسبات ساده عدد صحیح در شل
- `awk` — پردازش متن که محاسبات ریاضی هم پشتیبانی می‌کند
- `printf` — قالب‌بندی خروجی اعداد
