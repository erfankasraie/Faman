# Introduction

`locate` فایل‌ها را بر اساس یک پایگاه‌داده از‌پیش‌ساخته‌شده (index) جستجو می‌کند؛ در نتیجه بسیار سریع‌تر از `find` است، اما نتایج ممکن است شامل فایل‌های تازه‌ساخته‌شده که هنوز index نشده‌اند نباشند.

# Syntax

```
locate [OPTIONS] PATTERN
```

# Options

| گزینه | توضیح |
|-------|--------|
| `-i` | جستجوی بدون حساسیت به بزرگی/کوچکی حروف |
| `-c` | فقط تعداد نتایج (نه لیست کامل) |
| `-r REGEX` | جستجو با عبارت باقاعده (regex) |
| `-l N` | محدودکردن به N نتیجه اول |

# Examples

```bash
# جستجوی ساده یک فایل
locate myfile.txt

# جستجو بدون حساسیت به حروف بزرگ/کوچک
locate -i README

# فقط تعداد فایل‌های منطبق
locate -c "*.log"

# محدودکردن به ۱۰ نتیجه اول
locate -l 10 config

# به‌روزرسانی دستی پایگاه‌داده index (نیاز به sudo)
sudo updatedb

# جستجو با regex برای الگوی پیچیده‌تر
locate -r '\.conf$'
```

# Common mistakes

- انتظار داشتن دیدن فایلی که همین الان ساخته شده؛ `locate` فقط از یک پایگاه‌داده index (معمولاً به‌روزشده هر شب توسط cron) استفاده می‌کند، نه وضعیت زنده فایل‌سیستم. برای فایل‌های تازه از `find` استفاده کنید یا `sudo updatedb` را دستی اجرا کنید.
- در برخی توزیع‌ها `locate`/`mlocate` به‌صورت پیش‌فرض نصب نیست و باید نصب و `updatedb` اجرا شود.

# Tips

- `locate` برای جستجوی سریع فایل‌های قدیمی/ثابت روی سیستم عالی است؛ برای جستجوی دقیق و لحظه‌ای (بر اساس زمان تغییر، اندازه، یا فایل‌های تازه) از `find` استفاده کنید.
- اگر نتیجه `locate` قدیمی به‌نظر می‌رسد، ابتدا `sudo updatedb` را اجرا کنید تا index تازه شود.

# Related commands

- `find` — جستجوی زنده و دقیق‌تر (کندتر ولی همیشه به‌روز)
- `updatedb` — به‌روزرسانی دستی پایگاه‌داده locate
- `which` — پیداکردن مسیر یک فایل اجرایی خاص در PATH
