# Introduction

`fold` خطوط طولانی یک متن را در عرض مشخصی می‌شکند (word wrap) تا در ترمینال یا چاپ به‌درستی نمایش داده شوند.

# Syntax

```
fold [OPTIONS] [FILE]
```

# Options

| گزینه | توضیح |
|-------|--------|
| `-w N` | عرض هر خط بر حسب کاراکتر (پیش‌فرض ۸۰) |
| `-s` | شکستن فقط در فاصله بین کلمات (بدون بریدن وسط کلمه) |
| `-b` | شمارش بر اساس بایت به‌جای کاراکتر |

# Examples

```bash
# شکستن یک متن طولانی در عرض ۴۰ کاراکتر
fold -w 40 longtext.txt

# شکستن فقط در مرز کلمات (خواناتر)
fold -w 60 -s article.txt

# شکستن خروجی یک دستور برای نمایش بهتر
echo "یک متن خیلی طولانی که..." | fold -w 30 -s
```

# Common mistakes

- استفاده بدون `-s` که ممکن است وسط یک کلمه را بشکند و متن نامفهوم شود.
- اشتباه‌گرفتن `fold` با `fmt`؛ `fmt` علاوه بر شکستن، پاراگراف‌بندی هوشمندتری هم انجام می‌دهد.

# Tips

- برای متن فارسی و RTL، نتیجه `fold` ممکن است در برخی ترمینال‌ها عجیب دیده شود؛ بهتر است با `-s` تست کنید.
- برای پاراگراف‌بندی حرفه‌ای‌تر (نه فقط شکستن خط)، `fmt` گزینه بهتری است.

# Related commands

- `fmt` — پاراگراف‌بندی و شکستن هوشمندتر متن
- `cut` — بریدن متن بر اساس ستون (نه شکستن خط)
