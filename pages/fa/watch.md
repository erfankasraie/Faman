# Introduction

`watch` یک دستور را به‌طور مکرر (پیش‌فرض هر ۲ ثانیه) اجرا می‌کند و خروجی آن را در صفحه تازه‌سازی می‌کند؛ برای نظارت زنده روی مقادیری که تغییر می‌کنند (مثل مصرف دیسک، تعداد پردازش‌ها، وضعیت یک سرویس) بسیار مفید است.

# Syntax

```
watch [OPTIONS] COMMAND
```

# Options

| گزینه | توضیح |
|-------|--------|
| `-n SEC` | فاصله زمانی بین اجراها بر حسب ثانیه (پیش‌فرض ۲) |
| `-d` | برجسته‌کردن (highlight) تفاوت‌ها نسبت به اجرای قبلی |
| `-t` | مخفی‌کردن هدر (عنوان دستور و زمان) |
| `-g` | خروج خودکار وقتی خروجی دستور تغییر کرد |

# Examples

```bash
# نظارت زنده روی فضای دیسک هر ۲ ثانیه
watch df -h

# نظارت با فاصله ۵ ثانیه
watch -n 5 free -h

# نظارت با نمایش تغییرات برجسته‌شده
watch -d ls -la /var/log

# نظارت روی تعداد پردازش‌های یک برنامه خاص
watch 'ps aux | grep nginx | grep -v grep | wc -l'

# توقف خودکار به‌محض تغییر خروجی (مفید برای صبرکردن تا یک وضعیت خاص)
watch -g 'ls file.lock 2>/dev/null'
```

# Common mistakes

- فراموش‌کردن کوتیشن (quote) گذاشتن دور دستورات پیچیده با لوله (`|`) یا چند بخشی؛ بدون کوتیشن، شل ممکن است دستور را به‌شکل نادرست تفسیر کند.
- استفاده از `watch` برای دستوراتی که خودشان از‌قبل قابلیت زنده (live) دارند (مثل `top` یا `tail -f`)؛ این ابزارها نیازی به `watch` ندارند.

# Tips

- `watch -d` برای دیدن سریع اینکه دقیقاً چه چیزی بین دو اجرا تغییر کرده (مثلاً کدام فایل جدید در یک پوشه ظاهر شده) بسیار کاربردی است.
- برای صبرکردن در یک اسکریپت تا زمانی که یک شرط خاص برقرار شود (مثل ظاهرشدن یک فایل)، `watch -g` گزینه خوبی است، هرچند یک حلقه `while` با `sleep` هم جایگزین رایجی است.

# Related commands

- `tail -f` — دنبال‌کردن زنده یک فایل (نه اجرای مکرر دستور)
- `top` / `htop` — نظارت زنده اختصاصی پردازش‌ها (از قبل تکرارشونده)
- `sleep` — تأخیر ساده در اسکریپت (بدون تکرار خودکار)
