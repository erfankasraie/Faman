# Introduction

دستور `cd` (Change Directory) برای تغییر پوشه جاری استفاده می‌شود.

# Syntax

```
cd [DIRECTORY]
```

# Options

`cd` گزینه‌های کمی دارد و بیشتر از آرگومان‌های خاص استفاده می‌کند:

| آرگومان | معنی |
|---------|------|
| `cd` یا `cd ~` | رفتن به پوشه خانه |
| `cd -` | برگشت به پوشه قبلی |
| `cd ..` | یک سطح بالاتر |
| `cd ../..` | دو سطح بالاتر |
| `cd /` | رفتن به ریشه فایل‌سیستم |

# Examples

```bash
# رفتن به پوشه خانه
cd
cd ~

# رفتن به یک مسیر مطلق
cd /var/log

# رفتن به مسیر نسبی
cd projects/web

# برگشت به پوشه قبلی
cd -

# یک سطح بالاتر
cd ..
```

# Common mistakes

- فراموش کردن اینکه `cd` یک built-in شل است و در زیرفرایند کار نمی‌کند.
- استفاده از `cd` در اسکریپت بدون در نظر گرفتن اینکه مسیر ممکن است وجود نداشته باشد.

# Tips

- از `pushd` و `popd` برای مدیریت پشته پوشه‌ها استفاده کنید.
- می‌توانید alias تعریف کنید برای مسیرهای پرکاربرد.
- `CDPATH` به شما اجازه می‌دهد مسیرهای جستجو تعریف کنید.

# Related commands

- `pwd` — نمایش مسیر جاری
- `pushd` / `popd` — مدیریت پشته پوشه
- `ls` — دیدن محتویات
- `realpath` — مسیر مطلق
