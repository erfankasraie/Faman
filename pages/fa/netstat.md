# Introduction

`netstat` اتصالات شبکه، پورت‌های باز (listening)، جدول مسیریابی و آمار شبکه را نمایش می‌دهد. در بسیاری از توزیع‌های مدرن این ابزار منسوخ شده و جای خود را به `ss` داده است، اما هنوز در بسیاری از سیستم‌ها و اسکریپت‌های قدیمی استفاده می‌شود.

# Syntax

```
netstat [OPTIONS]
```

# Options

| گزینه | توضیح |
|-------|--------|
| `-t` | نمایش اتصالات TCP |
| `-u` | نمایش اتصالات UDP |
| `-l` | فقط پورت‌های در حال گوش‌دادن (listening) |
| `-n` | نمایش آدرس/پورت عددی به‌جای نام (سریع‌تر) |
| `-p` | نمایش نام برنامه/PID مربوط به هر اتصال |
| `-r` | نمایش جدول مسیریابی |

# Examples

```bash
# پورت‌های TCP در حال گوش‌دادن همراه با نام برنامه
sudo netstat -tlnp

# تمام اتصالات فعال (TCP و UDP)
netstat -tun

# جدول مسیریابی
netstat -r

# آمار کلی پروتکل‌های شبکه
netstat -s
```

# Common mistakes

- استفاده از `netstat` در توزیع‌های مدرن که ممکن است به‌صورت پیش‌فرض نصب نباشد (بسته `net-tools` باید نصب شود)؛ در این توزیع‌ها `ss` جایگزین توصیه‌شده است.
- فراموش‌کردن `sudo` برای دیدن نام برنامه صاحب هر اتصال (`-p`).

# Tips

- در سیستم‌های جدید، معادل سریع‌تر همین دستور: `ss -tlnp`
- برای پیدا کردن این‌که چه برنامه‌ای روی یک پورت خاص گوش می‌دهد: `sudo netstat -tlnp | grep :8080`

# Related commands

- `ss` — جایگزین مدرن و سریع‌تر netstat
- `lsof` — فایل‌ها و پورت‌های باز‌شده توسط پردازش‌ها
- `ip` — مدیریت شبکه و مسیریابی
