# Introduction

`killall` برخلاف `kill` (که با شماره پردازش یا PID کار می‌کند)، بر اساس **نام** پردازش عمل می‌کند و سیگنال را به تمام پردازش‌هایی که آن نام را دارند می‌فرستد.

# Syntax

```
killall [OPTIONS] NAME...
```

# Options

| گزینه | توضیح |
|-------|--------|
| `-9` | ارسال سیگنال SIGKILL (توقف اجباری فوری) |
| `-15` | ارسال SIGTERM (پیش‌فرض؛ درخواست خروج مؤدبانه) |
| `-i` | تأیید گرفتن قبل از کشتن هر پردازش |
| `-u USER` | فقط پردازش‌های یک کاربر خاص |
| `-v` | نمایش گزارش پس از اجرا |
| `-w` | صبرکردن تا پردازش‌ها واقعاً بمیرند |

# Examples

```bash
# کشتن مؤدبانه تمام پردازش‌های firefox
killall firefox

# توقف اجباری تمام پردازش‌های node
killall -9 node

# تأیید گرفتن قبل از هر بار کشتن
killall -i chrome

# فقط پردازش‌های یک کاربر خاص
killall -u ali python3
```

# Common mistakes

- ⚠️ روی سیستم‌های macOS دستور `killall` رفتار متفاوتی دارد و بدون آرگومان اضافی می‌تواند بسیاری از سرویس‌ها را ببندد؛ همیشه نام دقیق بدهید.
- اشتباه‌گرفتن نام فرایند (که با `ps` دیده می‌شود) با نام برنامه گرافیکی.
- استفاده از `-9` به‌عنوان اولین انتخاب؛ بهتر است ابتدا بدون آن (SIGTERM) امتحان کنید تا برنامه فرصت ذخیره‌سازی داشته باشد.

# Tips

- قبل از کشتن، با `pgrep NAME` مطمئن شوید کدام پردازش‌ها هدف قرار می‌گیرند.
- `killall -w` مفید است وقتی در اسکریپت نیاز دارید مطمئن شوید پردازش واقعاً تمام شده قبل از ادامه.

# Related commands

- `kill` — کشتن با PID
- `pkill` — کشتن بر اساس الگوی نام (شبیه killall ولی با regex)
- `pgrep` — پیداکردن PID بر اساس نام
- `ps` — لیست پردازش‌ها
