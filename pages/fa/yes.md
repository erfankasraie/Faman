# Introduction

`yes` یک رشته (پیش‌فرض "y") را بی‌نهایت بار و پشت‌سرهم چاپ می‌کند تا زمانی که متوقف شود. کاربرد اصلی‌اش پاسخ‌دادن خودکار به دستوراتی است که مدام تأیید (`y/n`) می‌خواهند.

# Syntax

```
yes [STRING]
```

# Options

`yes` گزینه‌ای ندارد؛ تنها آرگومان اختیاری، رشته‌ای است که به‌جای "y" پیش‌فرض تکرار می‌شود.

# Examples

```bash
# تولید بی‌نهایت "y" (باید با Ctrl+C متوقف شود)
yes

# پاسخ خودکار "y" به تمام تأییدهای یک دستور تعاملی
yes | apt-get remove some-package

# چاپ یک رشته دلخواه به‌جای y
yes "در حال پردازش..."

# محدودکردن تعداد خطوط با head (چون yes خودش متوقف نمی‌شود)
yes | head -n 5

# تست فشار ساده روی دیسک یا CPU (احتیاط: مصرف بالا)
yes > /dev/null &
```

# Common mistakes

- اجرای `yes` بدون لوله‌کردن (pipe) به جایی و بدون `Ctrl+C`؛ این دستور تا ابد اجرا می‌شود و می‌تواند CPU را اشغال کند.
- استفاده از `yes` برای تأیید خودکار عملیات حساس (مثل حذف فایل) بدون بررسی دقیق این‌که واقعاً باید بدون نظارت انسانی انجام شود یا نه.

# Tips

- ترکیب `yes | command` روش استانداردی برای خودکارسازی دستوراتی است که پرامپت‌های `[y/N]` دارند و گزینه `--yes`/`--force` ندارند.
- برای محدودکردن خروجی بی‌نهایت `yes`، همیشه با `head -n` یا مشابه آن ترکیب کنید.

# Related commands

- `head` — محدودکردن تعداد خطوط خروجی
- `xargs` — گاهی به‌جای yes برای تکرار یک عملیات استفاده می‌شود
- `apt-get -y` / `--yes` — بسیاری از ابزارها گزینه داخلی برای تأیید خودکار دارند که ترجیح داده می‌شود
