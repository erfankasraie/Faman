# Introduction

دستور `lsusb` تمام دستگاه‌های متصل به پورت‌های USB را همراه با شناسه فروشنده (vendor ID) و محصول (product ID) لیست می‌کند.

برای مبتدیان: وقتی یک فلش، ماوس یا هر دستگاه USB وصل می‌کنید و می‌خواهید مطمئن شوید سیستم آن را شناسایی کرده، از `lsusb` استفاده کنید.

# Syntax

```
lsusb [OPTIONS]
```

# Options

| گزینه | توضیح |
|-------|--------|
| `-v` | نمایش اطلاعات کامل و فنی (verbose) |
| `-t` | نمایش به‌صورت درختی بر اساس هاب‌ها |
| `-d VID:PID` | فیلتر بر اساس شناسه فروشنده/محصول خاص |

# Examples

```bash
# لیست ساده دستگاه‌های USB
lsusb

# نمایش ساختار درختی هاب‌ها و دستگاه‌ها
lsusb -t

# اطلاعات کامل یک دستگاه خاص
lsusb -v -d 046d:c52b

# دنبال‌کردن پیام‌های اتصال جدید
dmesg -w
```

# Common mistakes

- در برخی توزیع‌ها `lsusb` به‌صورت پیش‌فرض نصب نیست و باید بسته `usbutils` نصب شود.
- اجرای `-v` بدون فیلتر خروجی بسیار طولانی و شلوغ تولید می‌کند.

# Tips

- برای پیدا کردن نام دقیق دستگاه پس از اتصال، `lsusb` را قبل و بعد از اتصال مقایسه کنید.
- `lsusb -t` برای فهمیدن اینکه یک دستگاه به کدام هاب فیزیکی وصل است مفید است.

# Related commands

- `lspci` — لیست دستگاه‌های PCI
- `dmesg` — لاگ کرنل هنگام اتصال دستگاه
- `lsblk` — لیست دستگاه‌های بلوکی (دیسک‌ها)
