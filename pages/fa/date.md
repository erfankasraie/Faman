# Introduction

`date` تاریخ و زمان فعلی سیستم را نمایش می‌دهد یا (با دسترسی مناسب) تنظیم می‌کند. یکی از قدرتمندترین کاربردهایش قالب‌بندی دقیق تاریخ برای استفاده در اسکریپت‌ها است — مثلاً ساخت نام فایل بکاپ با تاریخ امروز.

# Syntax

```
date [OPTIONS] [+FORMAT]
```

# Options

| گزینه | توضیح |
|-------|--------|
| `+FORMAT` | قالب دلخواه خروجی (مثل `+%Y-%m-%d`) |
| `-d STRING` | نمایش تاریخ بر اساس یک عبارت (نه لزوماً امروز) |
| `-u` | نمایش زمان به‌وقت UTC |
| `-s STRING` | تنظیم تاریخ/زمان سیستم (نیاز به sudo) |
| `-R` | قالب RFC 2822 (استاندارد برای ایمیل) |
| `-I` | قالب ISO 8601 (`YYYY-MM-DD`) |

نمادهای رایج قالب‌بندی:

| نماد | معنی |
|------|------|
| `%Y` | سال ۴ رقمی |
| `%m` | ماه (۰۱–۱۲) |
| `%d` | روز ماه |
| `%H:%M:%S` | ساعت:دقیقه:ثانیه |
| `%A` | نام روز هفته (کامل) |
| `%s` | timestamp یونیکس (ثانیه از ۱۹۷۰) |

# Examples

```bash
# نمایش تاریخ و زمان فعلی
date

# قالب دلخواه برای نام فایل بکاپ
date +%Y-%m-%d
# → 2026-08-05

# ساخت نام فایل بکاپ با تاریخ و ساعت
backup_file="backup_$(date +%Y%m%d_%H%M%S).tar.gz"

# نمایش تاریخ دیروز
date -d "yesterday"

# نمایش تاریخ ۳ روز بعد
date -d "+3 days"

# محاسبه timestamp یونیکس فعلی
date +%s

# تبدیل یک timestamp یونیکس به تاریخ خوانا
date -d @1735689600

# نمایش زمان به‌وقت UTC
date -u

# تنظیم زمان سیستم (نیاز به sudo)
sudo date -s "2026-08-05 14:30:00"
```

# Common mistakes

- گیج‌شدن بین ترتیب `%d/%m/%Y` (روز/ماه/سال، رایج در ایران و اروپا) و `%m/%d/%Y` (ماه/روز/سال، رایج در آمریکا)؛ همیشه قالب دقیق را با `+` مشخص کنید تا ابهام نداشته باشد.
- استفاده از `date -s` بدون درنظرگرفتن این‌که تنظیم دستی ساعت می‌تواند سرویس‌های وابسته به زمان (مثل گواهی‌های SSL، لاگ‌ها، cron) را دچار مشکل کند؛ در سرورهای واقعی بهتر است از `timedatectl` و همگام‌سازی NTP استفاده شود، نه تنظیم دستی.
- فراموش‌کردن `+` قبل از قالب که باعث خطا یا رفتار غیرمنتظره می‌شود؛ مثلاً `date %Y` درست نیست، باید `date +%Y` باشد.

# Tips

- برای اسکریپت‌های بکاپ، الگوی `$(date +%Y%m%d_%H%M%S)` استاندارد صنعتی برای نام‌گذاری فایل‌های یکتا و مرتب است.
- برای محاسبه اختلاف زمانی بین دو تاریخ، از `%s` (timestamp) دو طرف کم کنید: `$(( $(date -d "2026-12-31" +%s) - $(date +%s) ))` ثانیه تا آن تاریخ باقی مانده.
- تقویم `date` استاندارد میلادی است؛ برای تقویم شمسی به ابزارهای جداگانه (مثل `jdate`) نیاز دارید.

# Related commands

- `cal` — نمایش تقویم ماهانه/سالانه
- `timedatectl` — مدیریت کامل زمان، منطقه زمانی و همگام‌سازی NTP
- `uptime` — مدت زمان روشن‌بودن سیستم
