# Introduction

دستور `echo` متن یا مقدار متغیرها را در خروجی استاندارد چاپ می‌کند. ساده‌ترین راه برای نمایش پیام در اسکریپت‌های شل است.

# Syntax

```
echo [OPTIONS] [STRING...]
```

# Options

| گزینه | توضیح |
|-------|--------|
| `-n` | بدون خط جدید در پایان |
| `-e` | تفسیر escape sequenceها (`\n`, `\t`, …) |
| `-E` | عدم تفسیر escape (پیش‌فرض در بسیاری از شل‌ها) |

# Examples

```bash
# چاپ ساده
echo "سلام دنیا"

# بدون خط جدید
echo -n "در حال بارگذاری..."

# با escape
echo -e "خط اول\nخط دوم"

# متغیر محیطی
echo "HOME=$HOME"

# خروجی به فایل
echo "لاگ جدید" >> app.log
```

# Common mistakes

- فراموش کردن کوتیشن وقتی متن فاصله دارد.
- انتظار رفتار یکسان `echo -e` در تمام شل‌ها (در بعضی شل‌ها `-e` پیش‌فرض نیست).
- استفاده از `echo` برای داده‌های باینری یا بسیار پیچیده — بهتر است از `printf` استفاده شود.

# Tips

- برای کنترل دقیق‌تر قالب از `printf` استفاده کنید.
- `echo $?` وضعیت خروج آخرین دستور را نشان می‌دهد.
- در اسکریپت‌های قابل حمل، `printf '%s\n' "$msg"` امن‌تر از `echo` است.

# Related commands

- `printf` — چاپ قالب‌دار
- `cat` — نمایش محتوای فایل
- `tee` — چاپ و نوشتن همزمان
