# Introduction

دستور `lspci` تمام دستگاه‌های متصل به گذرگاه PCI را نمایش می‌دهد؛ مثل کارت گرافیک، کارت شبکه و کنترلرهای دیسک.

# Syntax

```
lspci [OPTIONS]
```

# Options

| گزینه | توضیح |
|-------|--------|
| `-v` | اطلاعات کامل‌تر هر دستگاه |
| `-vv` | اطلاعات بسیار مفصل |
| `-k` | نمایش درایور کرنل استفاده‌شده برای هر دستگاه |
| `-nn` | نمایش شناسه‌های عددی همراه نام‌ها |
| `-s ADDR` | فیلتر بر اساس آدرس گذرگاه |

# Examples

```bash
# لیست ساده دستگاه‌های PCI
lspci

# نمایش کارت گرافیک و درایور آن
lspci -k | grep -A2 VGA

# اطلاعات کامل یک دستگاه خاص
lspci -vv -s 00:02.0

# جستجوی کارت شبکه
lspci | grep -i ethernet
```

# Common mistakes

- بدون `sudo` برخی اطلاعات دقیق (مثل bus mastering) نمایش داده نمی‌شود.
- اشتباه‌گرفتن `lspci` (دستگاه‌های داخلی مادربورد) با `lsusb` (دستگاه‌های خارجی USB).

# Tips

- `lspci -k` بهترین راه برای فهمیدن این است که آیا کرنل درایور مناسب برای کارت گرافیک یا شبکه را لود کرده یا نه.
- برای گزارش کامل سخت‌افزار همراه با PCI و USB، ابزار `inxi` هم مفید است (در صورت نصب بودن).

# Related commands

- `lsusb` — لیست دستگاه‌های USB
- `lsblk` — لیست دستگاه‌های ذخیره‌سازی
- `dmesg` — لاگ کرنل
