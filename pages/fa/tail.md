# Introduction

`tail` انتهای یک فایل یا خروجی یک دستور را نمایش می‌دهد؛ پیش‌فرض ۱۰ خط آخر. مهم‌ترین کاربرد آن حالت `-f` (follow) است که برای تماشای زنده لاگ‌های در حال رشد (مثل لاگ یک سرور یا اپلیکیشن) استفاده می‌شود — این یکی از پرکاربردترین دستورات در دیباگ‌کردن سرورها است.

# Syntax

```
tail [OPTIONS] [FILE...]
```

# Options

| گزینه | توضیح |
|-------|--------|
| `-n N` | نمایش N خط آخر (پیش‌فرض ۱۰) |
| `-n +N` | نمایش از خط N به بعد تا انتها |
| `-f` | دنبال‌کردن زنده (follow) — فایل جدید که اضافه می‌شود را هم نشان می‌دهد |
| `-F` | مثل `-f` ولی اگر فایل rotate/rename شد دوباره وصل می‌شود |
| `-c N` | نمایش N بایت آخر |
| `-q` | مخفی‌کردن هدر نام فایل هنگام چند فایل |

# Examples

```bash
# ۱۰ خط آخر (پیش‌فرض)
tail file.log

# ۵۰ خط آخر
tail -n 50 access.log

# تماشای زنده یک لاگ (رایج‌ترین کاربرد)
tail -f /var/log/syslog

# تماشای زنده چند لاگ همزمان
tail -f app.log error.log

# تماشای لاگی که ممکن است logrotate شود (بهتر از -f برای این حالت)
tail -F /var/log/nginx/access.log

# نمایش از خط ۱۰۰ به بعد تا انتها
tail -n +100 file.txt

# فیلترکردن لاگ زنده برای فقط خطوط خطا
tail -f app.log | grep --line-buffered ERROR
```

# Common mistakes

- استفاده از `-f` روی یک فایل که قرار است logrotate شود؛ در این حالت `tail -f` به فایل قدیمی (که دیگر آپدیت نمی‌شود) وصل می‌ماند. برای این سناریو از `-F` استفاده کنید.
- فراموش‌کردن `--line-buffered` هنگام لوله‌کردن (pipe) خروجی `tail -f` به `grep`؛ بدون آن ممکن است نتایج فیلترشده با تأخیر یا به‌صورت دسته‌ای نمایش داده شوند.
- بستن ترمینال به‌جای `Ctrl+C` برای خروج از حالت `-f`؛ این کار فرایند tail را در پس‌زمینه (اگر nohup شده باشد) رها می‌کند.

# Tips

- برای دیدن یک لاگ زنده و درعین‌حال جستجوی الگوی خاص در آن: `tail -f app.log | grep --line-buffered "ERROR\|WARN"`
- ترکیب با `head` برای برش دقیق میانی فایل: `tail -n +50 file | head -n 20` (خطوط ۵۰ تا ۶۹).
- برای سرورهای production، `journalctl -f` معادل مدرن‌تر برای لاگ‌های systemd است.

# Related commands

- `head` — نمایش ابتدای فایل
- `less +F` — مشاهده تعاملی همراه با قابلیت follow (مثل tail -f ولی با اسکرول)
- `journalctl -f` — دنبال‌کردن لاگ‌های systemd
- `watch` — اجرای مکرر یک دستور (نه لزوماً فایل)
