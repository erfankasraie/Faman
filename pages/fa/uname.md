# Introduction

`uname` اطلاعات پایه سیستم‌عامل و کرنل را نمایش می‌دهد: نام کرنل، نسخه، معماری پردازنده و نام میزبان. اولین دستوری است که برای فهمیدن «این سیستم دقیقاً چیست» (لینوکس/macOS، ۳۲ یا ۶۴ بیتی، کدام معماری) استفاده می‌شود.

# Syntax

```
uname [OPTIONS]
```

# Options

| گزینه | توضیح |
|-------|--------|
| `-a` | نمایش تمام اطلاعات (all) |
| `-r` | فقط نسخه کرنل |
| `-m` | فقط معماری سخت‌افزار (مثل x86_64, aarch64) |
| `-s` | فقط نام کرنل (پیش‌فرض، مثل Linux) |
| `-n` | نام میزبان (nodename) |
| `-o` | نام سیستم‌عامل |

# Examples

```bash
# نمایش کامل اطلاعات سیستم
uname -a

# فقط معماری (برای دانلود باینری درست، مثلاً x86_64 یا arm64)
uname -m

# فقط نسخه کرنل (برای بررسی سازگاری درایور یا ماژول)
uname -r

# استفاده در اسکریپت برای انتخاب باینری متناسب با معماری
arch=$(uname -m)
if [ "$arch" = "x86_64" ]; then
  echo "دانلود نسخه amd64"
fi
```

# Common mistakes

- گیج‌شدن `uname -a` (که اطلاعات کرنل را می‌دهد) با اطلاعات نسخه توزیع (مثل اوبونتو ۲۴.۰۴)؛ برای نسخه دقیق توزیع باید از `lsb_release -a` یا `cat /etc/os-release` استفاده کرد.
- فرض‌کردن `uname -m` روی همه سیستم‌ها یک خروجی یکسان دارد؛ مقادیر رایج شامل `x86_64`، `aarch64`، `armv7l` است و باید در اسکریپت با دقت مدیریت شوند.

# Tips

- برای دانلود باینری درست یک نرم‌افزار (اسکریپت‌های نصب خودکار معمولاً این‌طور کار می‌کنند): `uname -m` را چک کرده و بر اساس آن فایل amd64/arm64 مناسب را انتخاب کنید.
- برای اطلاعات کامل نسخه توزیع (نه فقط کرنل)، از `cat /etc/os-release` استفاده کنید که اطلاعات بیشتری (نام، نسخه، کد نسخه) می‌دهد.

# Related commands

- `hostnamectl` — اطلاعات کامل‌تر سیستم شامل نسخه توزیع
- `cat /etc/os-release` — اطلاعات دقیق توزیع لینوکس
- `lscpu` — اطلاعات دقیق پردازنده
