# Introduction

دستور `lscpu` اطلاعات کامل معماری پردازنده (CPU) سیستم را نمایش می‌دهد؛ از جمله تعداد هسته‌ها، تعداد رشته‌ها (threads)، سرعت، معماری و کش‌ها.

برای مبتدیان: اگر می‌خواهید بدانید سیستم شما چند هسته دارد یا چه نوع پردازنده‌ای است، این دستور را اجرا کنید.

# Syntax

```
lscpu [OPTIONS]
```

# Options

| گزینه | توضیح |
|-------|--------|
| `-e` | نمایش خلاصه به‌صورت جدول (extended) |
| `-p` | خروجی به‌صورت parsable برای اسکریپت‌نویسی |
| `-J` | خروجی JSON |
| `-a` | نمایش پردازنده‌های آنلاین و آفلاین |

# Examples

```bash
# نمایش کامل اطلاعات CPU
lscpu

# خروجی خلاصه و جدولی
lscpu -e

# خروجی JSON برای پردازش با jq
lscpu -J | jq '.lscpu[] | select(.field=="CPU(s):")'

# فقط تعداد هسته‌های منطقی
nproc
```

# Common mistakes

- اشتباه‌گرفتن «Core(s) per socket» با تعداد کل هسته‌ها؛ باید در تعداد سوکت‌ها ضرب شود.
- تصور اینکه «Thread(s) per core» همان تعداد هسته فیزیکی است (این‌ها به‌خاطر Hyper-Threading متفاوت‌اند).

# Tips

- برای فقط دیدن تعداد هسته‌های قابل استفاده، `nproc` سریع‌تر و ساده‌تر است.
- خط «Model name» معمولاً دقیق‌ترین نام پردازنده را نشان می‌دهد.

# Related commands

- `nproc` — تعداد هسته‌های پردازشی
- `free` — وضعیت حافظه رم
- `uname` — اطلاعات سیستم و کرنل
- `dmesg` — لاگ‌های کرنل شامل شناسایی سخت‌افزار
