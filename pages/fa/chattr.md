# Introduction

`chattr` ویژگی‌های خاص فایل‌سیستم (نه مجوزهای عادی مثل `chmod`) را روی فایل‌ها تغییر می‌دهد؛ مثلاً می‌تواند فایلی را «تغییرناپذیر» (immutable) کند که حتی کاربر root هم نتواند آن را حذف یا ویرایش کند مگر ویژگی برداشته شود.

# Syntax

```
chattr [OPTIONS] [+-=ATTRIBUTES] FILE
```

# Options (رایج‌ترین ویژگی‌ها)

| ویژگی | توضیح |
|-------|--------|
| `+i` | تغییرناپذیر (immutable) — حذف، ویرایش یا rename غیرممکن می‌شود |
| `+a` | فقط‌الحاقی (append-only) — فقط می‌توان به انتها اضافه کرد |
| `-i` / `-a` | برداشتن ویژگی |
| `-R` | اعمال بازگشتی روی پوشه‌ها |
| `-V` | نمایش جزئیات هنگام اجرا |

# Examples

```bash
# محافظت از یک فایل تنظیمات حساس در برابر حذف یا تغییر تصادفی
sudo chattr +i /etc/important-config.conf

# برداشتن حالت immutable برای ویرایش دوباره
sudo chattr -i /etc/important-config.conf

# ساخت یک فایل لاگ که فقط می‌توان به آن اضافه کرد، نه ویرایش یا حذف
sudo chattr +a /var/log/audit.log

# اعمال روی یک پوشه کامل به‌صورت بازگشتی
sudo chattr -R +i /etc/critical-configs/
```

# Common mistakes

- فراموش‌کردن این‌که فایل با `+i` حتی توسط `root` هم قابل حذف نیست تا زمانی که خودتان `-i` را اعمال کنید؛ این می‌تواند در اسکریپت‌های نصب/حذف خودکار مشکل ایجاد کند.
- تصور اینکه `chattr` روی همه فایل‌سیستم‌ها پشتیبانی می‌شود؛ برخی ویژگی‌ها فقط روی ext2/3/4 و مشابه کار می‌کنند، نه لزوماً روی هر فایل‌سیستمی (مثلاً برخی سیستم‌های شبکه‌ای).

# Tips

- برای بررسی ویژگی‌های فعلی یک فایل، از `lsattr` استفاده کنید.
- `+i` روش خوبی برای محافظت از فایل‌های حیاتی سیستم (مثل `/etc/passwd` در سناریوهای خاص امنیتی) در برابر تغییر تصادفی یا حتی برخی حملات است.

# Related commands

- `lsattr` — نمایش ویژگی‌های فعلی یک فایل
- `chmod` — تغییر مجوزهای دسترسی معمولی (متفاوت از ویژگی‌های فایل‌سیستم)
- `chown` — تغییر مالکیت فایل
