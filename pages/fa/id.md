# Introduction

`id` شناسه‌های کاربر جاری (یا یک کاربر دیگر) را نشان می‌دهد: UID (شناسه عددی کاربر)، GID (شناسه گروه اصلی) و لیست تمام گروه‌هایی که کاربر عضو آن‌هاست. برای عیب‌یابی مشکلات دسترسی (مثلاً «چرا این کاربر به این فایل دسترسی ندارد») نقطه شروع خوبی است.

# Syntax

```
id [OPTIONS] [USERNAME]
```

# Options

| گزینه | توضیح |
|-------|--------|
| `-u` | فقط UID (شناسه عددی کاربر) |
| `-g` | فقط GID گروه اصلی |
| `-G` | لیست تمام GIDهای گروه‌ها |
| `-n` | نمایش نام به‌جای عدد (همراه با `-u`/`-g`/`-G`) |
| `-un` | نام کاربری فعلی (ترکیب رایج) |

# Examples

```bash
# نمایش کامل شناسه کاربر فعلی
id

# فقط UID عددی
id -u

# فقط نام کاربری فعلی (بدون بقیه اطلاعات)
id -un

# بررسی شناسه یک کاربر دیگر
id ali

# بررسی این‌که آیا کاربر جاری عضو گروه docker است یا نه
id -nG | grep -w docker

# استفاده در اسکریپت برای بررسی اجرا با root
if [ "$(id -u)" -eq 0 ]; then
  echo "در حال اجرا با root"
fi
```

# Common mistakes

- تصور اینکه تغییردادن گروه‌های کاربر (مثلاً با `usermod -aG`) فوراً روی نشست (session) فعلی اثر می‌گذارد؛ کاربر باید دوباره login کند یا `newgrp` بزند تا `id` گروه جدید را نشان دهد.
- گیج‌شدن بین UID (شناسه خود کاربر) و GID گروه اصلی؛ این دو معمولاً یکسان نیستند مگر در تنظیمات خاص.

# Tips

- الگوی `if [ "$(id -u)" -eq 0 ]` روش استاندارد در اسکریپت‌های bash برای بررسی اجرا با دسترسی root است (به‌جای پارس‌کردن whoami).
- برای بررسی سریع این‌که آیا کاربر به یک گروه خاص (مثل `docker` یا `sudo`) اضافه شده: `id -nG username | grep -w groupname`

# Related commands

- `whoami` — فقط نام کاربری فعلی (ساده‌تر از `id -un`)
- `groups` — لیست گروه‌های یک کاربر
- `who` — کاربران فعلاً login شده در سیستم
- `sudo` — اجرای دستور با دسترسی کاربر دیگر
