# Introduction

دستور `ls` (مخفف list) یکی از پرکاربردترین دستورات لینوکس است. این دستور محتویات یک پوشه را لیست می‌کند.

برای مبتدیان: وقتی وارد یک پوشه می‌شوید و می‌خواهید ببینید چه فایل‌ها و پوشه‌هایی داخل آن است، از `ls` استفاده کنید.

# Syntax

```
ls [OPTIONS] [FILE...]
```

- بدون هیچ آرگومانی، محتویات پوشه جاری را نشان می‌دهد.
- می‌توانید یک یا چند مسیر فایل/پوشه به آن بدهید.

# Options

| گزینه | توضیح |
|-------|--------|
| `-l` | نمایش جزئیات کامل (long format) |
| `-a` | نمایش فایل‌های مخفی (که با `.` شروع می‌شوند) |
| `-h` | اندازه فایل‌ها را به صورت خوانا نشان بده (human-readable) |
| `-R` | به صورت بازگشتی تمام زیر‌پوشه‌ها را هم لیست کن |
| `-t` | مرتب‌سازی بر اساس زمان تغییر |
| `-S` | مرتب‌سازی بر اساس اندازه |
| `-r` | معکوس کردن ترتیب مرتب‌سازی |
| `-1` | هر فایل در یک خط جدا |
| `--color=auto` | رنگ‌آمیزی خروجی (معمولاً پیش‌فرض است) |

ترکیب محبوب: `ls -lah`

# Examples

```bash
# لیست ساده پوشه جاری
ls

# نمایش جزئیات کامل + فایل‌های مخفی + اندازه خوانا
ls -lah

# فقط فایل‌های مخفی
ls -a

# لیست یک پوشه خاص
ls /var/log

# مرتب‌سازی بر اساس زمان (جدیدترین اول)
ls -lt

# نمایش فقط نام پوشه‌ها
ls -d */
```

# Common mistakes

- فراموش کردن `-a` و تعجب از اینکه فایل `.bashrc` دیده نمی‌شود.
- استفاده از `ls *` به جای `ls` وقتی تعداد فایل‌ها خیلی زیاد است (ممکن است خطای «argument list too long» بدهد).
- فکر کردن که `ls -l` اندازه واقعی روی دیسک را نشان می‌دهد (در واقع اندازه منطقی فایل است).

# Tips

- برای دیدن نوع فایل‌ها از `ls -F` استفاده کنید (`/` برای پوشه، `*` برای اجرایی).
- می‌توانید خروجی را به `less` بدهید: `ls -l | less`
- در بسیاری از توزیع‌ها aliasی به نام `ll` برای `ls -l` تعریف شده است.
- برای رنگ‌آمیزی همیشه از `--color=auto` استفاده کنید تا در pipe مشکل ایجاد نشود.

# Related commands

- `tree` — نمایش درختی پوشه‌ها
- `find` — جستجوی پیشرفته فایل‌ها
- `stat` — اطلاعات دقیق یک فایل
- `du` — فضای اشغال‌شده
- `dir` — معادل قدیمی‌تر (کمتر استفاده می‌شود)
