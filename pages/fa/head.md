# Introduction

`head` ابتدای یک فایل یا خروجی یک دستور را نمایش می‌دهد؛ پیش‌فرض ۱۰ خط اول. بیشتر از یک نمایشگر ساده، اولین ابزاری است که برای «نگاه سریع» به یک فایل بزرگ (لاگ، CSV، خروجی دستور دیگر) بدون بازکردن کامل آن استفاده می‌شود.

برای مبتدیان: قبل از باز کردن یک فایل حجیم در ویرایشگر (که ممکن است طول بکشد یا سیستم را سنگین کند)، همیشه اول `head` بزنید تا ببینید ساختار و فرمت داده چیست.

# Syntax

```
head [OPTIONS] [FILE...]
```

# Options

| گزینه | توضیح |
|-------|--------|
| `-n N` | نمایش N خط اول (پیش‌فرض ۱۰) |
| `-n -N` | نمایش همه به‌جز N خط آخر |
| `-c N` | نمایش N بایت اول به‌جای خط |
| `-q` | مخفی‌کردن هدر نام فایل هنگام چند فایل |
| `-v` | نمایش همیشگی هدر نام فایل حتی برای یک فایل |

# Examples

```bash
# ۱۰ خط اول (پیش‌فرض)
head file.txt

# ۲۰ خط اول
head -n 20 file.txt

# همه خطوط به‌جز ۵ خط آخر
head -n -5 file.txt

# ۵۰ بایت اول (مفید برای بررسی نوع فایل باینری)
head -c 50 file.bin

# پیش‌نمایش چند فایل با هدر نام هرکدام
head -n 5 *.log

# ترکیب با یک دستور دیگر برای دیدن چند سطر اول خروجی
ps aux | head

# دیدن ابتدای یک فایل CSV برای فهمیدن نام ستون‌ها
head -n 1 data.csv
```

# Common mistakes

- استفاده از سینتکس قدیمی `head -20` (بدون `-n`)؛ در بسیاری از سیستم‌های مدرن هنوز کار می‌کند اما منسوخ است و بهتر است `-n 20` نوشته شود.
- فراموش‌کردن این‌که `head` روی فایل‌های باینری هم اجرا می‌شود و ممکن است کاراکترهای عجیب در ترمینال چاپ کند؛ برای فایل باینری از `-c` یا ابزار `xxd`/`hexdump` استفاده کنید.
- تصور اینکه `head` فایل را تغییر می‌دهد؛ فقط نمایش می‌دهد، چیزی را ویرایش یا حذف نمی‌کند.

# Tips

- ترکیب کلاسیک `head` و `tail` برای برش وسط یک فایل: `head -n 100 file | tail -n 20` (خطوط ۸۱ تا ۱۰۰).
- برای دیدن ستون‌های یک فایل CSV بزرگ بدون بازکردنش: `head -1 data.csv`
- اگر فقط می‌خواهید بدانید فایل خالی است یا نه، بدون خواندن کل آن: `head -c1 file | wc -c`

# Related commands

- `tail` — نمایش انتهای فایل
- `less` / `more` — مرور تعاملی کل فایل
- `sed -n '1,20p'` — جایگزین دقیق‌تر برای نمایش بازه خاصی از خطوط
- `wc` — شمارش خطوط/کلمات/بایت‌های یک فایل
