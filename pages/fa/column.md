# Introduction

`column` متن ساده را به‌صورت جدول مرتب و تراز‌شده (aligned) نمایش می‌دهد؛ بسیار مفید برای خواناکردن خروجی فایل‌های CSV یا داده‌های جداشده با فاصله/تب.

# Syntax

```
column [OPTIONS] [FILE]
```

# Options

| گزینه | توضیح |
|-------|--------|
| `-t` | نمایش به‌صورت جدول با تراز‌بندی خودکار ستون‌ها |
| `-s SEP` | تعیین کاراکتر جداکننده ورودی |
| `-o SEP` | تعیین کاراکتر جداکننده خروجی |
| `-N NAMES` | تعیین نام ستون‌ها (در نسخه‌های جدید util-linux) |

# Examples

```bash
# نمایش یک فایل CSV به‌صورت جدول خوانا
column -t -s ',' data.csv

# تبدیل خروجی /etc/passwd (جداشده با :) به جدول
column -t -s ':' /etc/passwd

# ترکیب با دستورات دیگر
df -h | column -t

# نمایش خروجی ps به‌صورت جدول‌بندی‌شده بهتر
ps aux | column -t
```

# Common mistakes

- فراموش‌کردن `-t`؛ بدون آن `column` فقط ستون‌ها را کنار هم می‌چیند بدون تراز واقعی جدولی.
- استفاده روی فایل‌هایی با تعداد ستون نامنظم که باعث جابه‌جایی داده در ستون‌های اشتباه می‌شود.

# Tips

- برای خواناکردن سریع هر خروجی جدول‌مانند در ترمینال، لوله (pipe) کردن به `column -t` یک عادت خیلی خوب است.
- بسیاری از ابزارهای CLI (مثل `docker ps`، `kubectl get`) از‌قبل خروجی تراز‌شده می‌دهند، اما برای ابزارهای ساده‌تر `column -t` جایگزین خوبی است.
