# Introduction

`shuf` خطوط یک فایل یا ورودی را به‌صورت تصادفی به‌هم می‌ریزد (shuffle)؛ برای انتخاب تصادفی یا تست‌های آماری کاربرد دارد.

# Syntax

```
shuf [OPTIONS] [FILE]
```

# Options

| گزینه | توضیح |
|-------|--------|
| `-n N` | فقط N خط تصادفی خروجی بده |
| `-i LOW-HIGH` | تولید اعداد تصادفی در یک بازه به‌جای خواندن فایل |
| `-e` | هر آرگومان به‌عنوان یک گزینه در نظر گرفته شود |
| `-r` | امکان تکرار در انتخاب (with replacement) |

# Examples

```bash
# به‌هم‌ریختن ترتیب خطوط یک فایل
shuf names.txt

# انتخاب تصادفی ۵ خط از یک فایل
shuf -n 5 names.txt

# تولید یک عدد تصادفی بین ۱ تا ۱۰۰
shuf -i 1-100 -n 1

# انتخاب تصادفی یکی از چند گزینه داده‌شده
shuf -e "قرمز" "آبی" "سبز" -n 1
```

# Common mistakes

- استفاده از `sort -R` به‌عنوان جایگزین `shuf` که برای فایل‌های بزرگ کندتر و کمتر تصادفی است.

# Tips

- `shuf -i 1-100 -n 1` روش ساده و سریعی برای تولید عدد تصادفی در اسکریپت‌های شل است (بدون نیاز به `$RANDOM`).
- برای انتخاب تصادفی یک فایل از یک پوشه: `ls *.txt | shuf -n 1`

# Related commands

- `sort` — مرتب‌سازی (با `-R` هم می‌تواند تصادفی کند ولی کندتر است)
- `$RANDOM` — متغیر تصادفی داخلی bash
