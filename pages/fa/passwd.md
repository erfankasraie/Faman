# Introduction

`passwd` رمز عبور کاربر جاری (یا با دسترسی root، رمز هر کاربر دیگر) را تغییر می‌دهد. همچنین می‌تواند برای قفل‌کردن/بازکردن حساب کاربری یا مدیریت انقضای رمز عبور استفاده شود.

# Syntax

```
passwd [OPTIONS] [USERNAME]
```

# Options

| گزینه | توضیح |
|-------|--------|
| `-l` | قفل‌کردن حساب کاربری (بدون حذف) |
| `-u` | بازکردن قفل حساب |
| `-e` | اجبار به تغییر رمز در ورود بعدی |
| `-S` | نمایش وضعیت حساب (قفل/باز، تاریخ آخرین تغییر) |
| `-d` | حذف رمز عبور (خطرناک — کاربر بدون رمز می‌شود) |

# Examples

```bash
# تغییر رمز عبور کاربر جاری
passwd

# تغییر رمز یک کاربر دیگر (نیاز به sudo)
sudo passwd ali

# قفل‌کردن یک حساب کاربری (بدون حذف آن)
sudo passwd -l ali

# بازکردن قفل حساب
sudo passwd -u ali

# مشاهده وضعیت رمز عبور یک کاربر
sudo passwd -S ali

# اجبار کاربر به تغییر رمز در اولین ورود بعدی
sudo passwd -e ali
```

# Common mistakes

- استفاده از `passwd -d` (حذف کامل رمز) به‌جای `passwd -l` (قفل‌کردن) برای غیرفعال‌کردن موقت یک حساب؛ حذف رمز می‌تواند حساب را بدون رمز و در برخی تنظیمات قابل‌ورود بدون احراز هویت کند — `-l` امن‌تر است.
- فراموش‌کردن این‌که تغییر رمز عبور کاربر دیگر نیاز به `sudo` دارد؛ کاربران عادی فقط می‌توانند رمز خودشان را تغییر دهند.

# Tips

- برای غیرفعال‌کردن موقت یک حساب کارمند سابق یا حساب مشکوک، `passwd -l` (قفل) نسبت به حذف کامل کاربر روش امن‌تر و برگشت‌پذیرتری است.
- ترکیب `chage` با `passwd` برای سیاست‌های امنیتی کامل‌تر (مثل انقضای اجباری رمز هر ۹۰ روز) استفاده می‌شود.

# Related commands

- `chage` — مدیریت دقیق‌تر انقضا و سیاست‌های رمز عبور
- `useradd` / `usermod` — ساخت و ویرایش حساب‌های کاربری
- `su` / `sudo` — اجرای دستور با هویت کاربر دیگر
