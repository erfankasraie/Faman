# Introduction

`nl` شماره خط به ابتدای هر خط یک فایل متنی اضافه می‌کند؛ شبیه `cat -n` ولی با کنترل بیشتر روی قالب شماره‌گذاری.

# Syntax

```
nl [OPTIONS] [FILE]
```

# Options

| گزینه | توضیح |
|-------|--------|
| `-b a` | شماره‌گذاری تمام خطوط (حتی خالی) |
| `-b t` | فقط خطوط غیرخالی (پیش‌فرض) |
| `-w N` | عرض ستون شماره |
| `-s SEP` | جداکننده بین شماره و متن |
| `-i N` | فاصله بین شماره‌ها (گام شمارش) |

# Examples

```bash
# شماره‌گذاری ساده خطوط غیرخالی
nl file.txt

# شماره‌گذاری تمام خطوط از جمله خالی‌ها
nl -b a file.txt

# شماره‌گذاری با گام ۲ (فقط زوج)
nl -i 2 file.txt

# تغییر جداکننده بین شماره و متن
nl -s ') ' file.txt
```

# Common mistakes

- انتظار داشتن شماره‌گذاری خطوط خالی به‌صورت پیش‌فرض؛ پیش‌فرض `nl` فقط خطوط غیرخالی را شماره می‌زند (برخلاف `cat -n` که همه را شماره می‌زند).

# Tips

- برای شماره‌گذاری ساده و سریع بدون گزینه‌های اضافه، `cat -n file.txt` معمولاً کافی و ساده‌تر است.
- `nl` برای قالب‌بندی‌های خاص (مثل چاپ رسمی کد) گزینه‌های دقیق‌تری نسبت به `cat -n` دارد.

# Related commands

- `cat` — نمایش با `-n` هم شماره‌گذاری می‌کند
- `head` / `tail` — نمایش بخشی از فایل
- `wc` — شمارش خطوط
