# Introduction

دستور `rm` برای حذف فایل‌ها و پوشه‌ها استفاده می‌شود.

**هشدار مهم:** فایل‌های حذف‌شده با `rm` معمولاً قابل بازیابی نیستند (برخلاف سطل زباله در محیط گرافیکی).

# Syntax

```
rm [OPTIONS] FILE...
```

# Options

| گزینه | توضیح |
|-------|--------|
| `-r` یا `-R` | حذف بازگشتی پوشه‌ها |
| `-f` | بدون سؤال و بدون خطا برای فایل‌های ناموجود (force) |
| `-i` | قبل از هر حذف سؤال کند |
| `-v` | نمایش فایل‌های حذف‌شده |
| `-d` | حذف پوشه‌های خالی (مثل rmdir) |

# Examples

```bash
# حذف یک فایل
rm file.txt

# حذف چندین فایل
rm *.tmp

# حذف پوشه و تمام محتویاتش
rm -r old_project/

# حذف ایمن با تأیید
rm -i important.txt

# حذف اجباری (خطرناک)
rm -rf /path/to/dir
```

# Common mistakes

- اجرای `rm -rf /` یا `rm -rf /*` → فاجعه.
- استفاده از `-f` بدون فکر → حذف غیرقابل‌بازگشت.
- حذف فایل‌های در حال استفاده بدون اطلاع.

# Tips

- هرگز `rm -rf` را با مسیرهای مطلق حساس ترکیب نکنید.
- برای حذف ایمن‌تر از `trash-cli` یا ابزارهای سطل زباله استفاده کنید.
- قبل از `rm -r` حتماً با `ls` محتویات را بررسی کنید.
- می‌توانید alias تعریف کنید: `alias rm='rm -i'`

# Related commands

- `rmdir` — حذف پوشه خالی
- `unlink` — حذف یک فایل
- `shred` — حذف امن با بازنویسی
- `find ... -delete` — حذف پیشرفته
