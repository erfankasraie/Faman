# Introduction

`whoami` نام کاربر مؤثر فعلی را چاپ می‌کند.

# Syntax

```
whoami
```

# Options

گزینه خاصی ندارد.

# Examples

```bash
whoami
sudo whoami   # معمولاً root
```

# Common mistakes

- تفاوت با `who` که کاربران لاگین‌شده را لیست می‌کند.

# Tips

- معادل تقریبی: `id -un`

# Related commands

- `id` — جزئیات بیشتر
- `who` / `w` — نشست‌های لاگین
