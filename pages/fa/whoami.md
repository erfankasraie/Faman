# Introduction

`whoami` فقط نام کاربری فعلی که با آن نشست ترمینال در حال اجراست را نمایش می‌دهد؛ ساده‌ترین راه برای پاسخ به «الان با کدام کاربر وارد شده‌ام».

# Syntax

```
whoami
```

# Options

`whoami` هیچ گزینه‌ی کاربردی‌ای ندارد؛ فقط نام کاربری فعلی را چاپ می‌کند.

# Examples

```bash
# نمایش نام کاربری فعلی
whoami

# بررسی این‌که آیا با root وارد شده‌اید
if [ "$(whoami)" = "root" ]; then
  echo "شما root هستید"
fi

# استفاده در prompt یا لاگ اسکریپت
echo "اجرا شده توسط: $(whoami) در $(date)"
```

# Common mistakes

- گیج‌شدن `whoami` (کاربری که واقعاً دستور را اجرا می‌کند، حتی بعد از `sudo`) با `$USER` (متغیر محیطی که همیشه کاربر اصلی login را نشان می‌دهد و ممکن است بعد از `su` به‌روزرسانی نشود).
- استفاده از `whoami` برای بررسی root بودن در اسکریپت‌های حساس؛ روش استاندارد و قابل‌اعتمادتر `[ "$(id -u)" -eq 0 ]` است چون به نام کاربری وابسته نیست.

# Tips

- برای بررسی دقیق‌تر و استانداردتر «آیا با root اجرا می‌شود»، `id -u` (که برای root همیشه صفر است) نسبت به `whoami` قابل‌اعتمادتر است.
- `whoami` معادل ساده‌شده `id -un` است.

# Related commands

- `id` — اطلاعات کامل‌تر شامل UID، GID و گروه‌ها
- `who` — لیست تمام کاربران login شده در سیستم
- `w` — کاربران login شده به‌همراه فعالیت فعلی‌شان
