# Introduction

`csplit` یک فایل را بر اساس الگو (pattern) یا شماره خط به چند فایل جداگانه تقسیم می‌کند؛ برخلاف `split` که فقط بر اساس حجم یا تعداد خط ثابت تقسیم می‌کند.

# Syntax

```
csplit [OPTIONS] FILE PATTERN...
```

# Options

| گزینه | توضیح |
|-------|--------|
| `-f PREFIX` | پیشوند نام فایل‌های خروجی |
| `-b FORMAT` | قالب شماره‌گذاری فایل‌ها |
| `-z` | حذف فایل‌های خروجی خالی |
| `-s` | حالت ساکت (بدون نمایش اندازه فایل‌ها) |

# Examples

```bash
# تقسیم فایل در هر خطی که با "Chapter" شروع می‌شود
csplit -z book.txt '/^Chapter/' '{*}'

# تقسیم فایل در شماره خط مشخص
csplit file.txt 10 20 30

# تقسیم با پیشوند دلخواه برای فایل‌های خروجی
csplit -f section_ -z log.txt '/ERROR/' '{*}'
```

# Common mistakes

- فراموش‌کردن `-z` که باعث می‌شود فایل‌های خروجی خالی (وقتی الگو در ابتدای فایل است) هم ساخته شوند.
- گیج‌شدن با سینتکس الگو؛ `{*}` یعنی «تا جایی که الگو پیدا می‌شود، تکرار کن».

# Tips

- برای تقسیم ساده بر اساس تعداد خط یا حجم ثابت، `split` ساده‌تر است؛ `csplit` را برای تقسیم بر اساس محتوا (مثل فصل‌های یک کتاب یا بخش‌های یک لاگ) نگه دارید.

# Related commands

- `split` — تقسیم فایل بر اساس حجم یا تعداد خط ثابت
- `grep` — پیداکردن خطوط منطبق با یک الگو
- `sed` — پردازش و ویرایش متن بر اساس الگو
