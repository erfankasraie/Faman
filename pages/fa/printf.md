# Introduction

`printf` متن را با قالب‌بندی دقیق (مشابه تابع printf در C) چاپ می‌کند. برخلاف `echo`، کنترل کاملی روی نحوه نمایش اعداد، رشته‌ها و کاراکترهای خاص می‌دهد و رفتار آن در پوسته‌های مختلف یکسان‌تر است.

# Syntax

```
printf FORMAT [ARGUMENTS...]
```

# Options

قالب‌های رایج (format specifiers):

| نشانه | توضیح |
|-------|--------|
| `%s` | رشته |
| `%d` | عدد صحیح |
| `%f` | عدد اعشاری |
| `%x` | عدد به‌صورت هگزادسیمال |
| `%%` | چاپ خود علامت درصد |
| `\n` | خط جدید |
| `\t` | تب |

# Examples

```bash
# چاپ ساده با خط جدید
printf "سلام %s\n" "دنیا"

# قالب‌بندی عدد اعشاری با دو رقم اعشار
printf "قیمت: %.2f\n" 19.5

# چاپ جدول ساده با تراز‌بندی
printf "%-10s %5d\n" "نام" 100

# تکرار روی چند آرگومان (format دوباره استفاده می‌شود)
printf "%s\n" اول دوم سوم

# چاپ بدون خط جدید (برخلاف echo)
printf "بدون خط جدید"
```

# Common mistakes

- فراموش‌کردن `\n` در انتها؛ برخلاف `echo`، `printf` به‌صورت خودکار خط جدید اضافه نمی‌کند.
- ندادن آرگومان کافی برای تعداد `%s`/`%d` موجود در قالب که باعث چاپ خالی یا صفر می‌شود.

# Tips

- برای اسکریپت‌نویسی قابل‌حمل (portable) بین پوسته‌های مختلف، `printf` نسبت به `echo` رفتار قابل‌پیش‌بینی‌تری دارد.
- می‌توانید از `printf` برای تبدیل عدد به هگز یا برعکس هم استفاده کنید: `printf "%x\n" 255`
