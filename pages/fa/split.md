# Introduction

`split` یک فایل بزرگ را به چند فایل کوچک‌تر تقسیم می‌کند؛ مثلاً برای آپلود در سرویس‌هایی با محدودیت حجم، یا برای پردازش موازی.

# Syntax

```
split [OPTIONS] FILE [PREFIX]
```

# Options

| گزینه | توضیح |
|-------|--------|
| `-b SIZE` | تقسیم بر اساس حجم (مثلاً `100M`) |
| `-l N` | تقسیم بر اساس تعداد خط در هر فایل |
| `-n N` | تقسیم به تعداد مشخصی فایل مساوی |
| `-d` | استفاده از پسوند عددی به‌جای حروف الفبا |

# Examples

```bash
# تقسیم فایل بزرگ به قطعات ۱۰۰ مگابایتی
split -b 100M bigfile.iso part_

# تقسیم یک فایل متنی به فایل‌های ۱۰۰۰ خطی
split -l 1000 access.log log_part_

# تقسیم به دقیقاً ۴ فایل مساوی
split -n 4 data.csv chunk_

# استفاده از پسوند عددی (part_00, part_01, ...)
split -d -b 50M archive.zip part_

# بازچسباندن قطعات به فایل اصلی
cat part_* > bigfile_rebuilt.iso
```

# Common mistakes

- فراموش‌کردن این‌که ترتیب فایل‌ها هنگام `cat part_*` باید حروف‌الفبایی/عددی صحیح داشته باشد (استفاده از `-d` با ارقام کافی مثل `-d -a 3` کمک می‌کند).
- تقسیم فایل‌های باینری با `-l` (خط) که برای فایل متنی معنا دارد نه باینری؛ برای باینری از `-b` استفاده کنید.

# Tips

- برای آپلود فایل‌های بزرگ در سرویس‌های ایمیل یا کلود با محدودیت حجم، `split -b` بسیار کاربردی است.
- برای بازسازی دقیق فایل اصلی، حتماً از همان ترتیب و روش تقسیم استفاده کنید؛ `cat` قطعات را به همان ترتیب نام فایل به هم می‌چسباند.

# Related commands

- `cat` — بازچسباندن قطعات به فایل اصلی
- `tar` — بایگانی و فشرده‌سازی (که خودش هم گزینه تقسیم چندجلدی دارد)
- `xargs` — پردازش موازی روی داده‌های تقسیم‌شده
