# Introduction

`nice` یک برنامه را با اولویت زمان‌بندی (scheduling priority) متفاوت از حالت پیش‌فرض اجرا می‌کند. عدد nice از ۱۹- (بالاترین اولویت) تا ۱۹ (پایین‌ترین اولویت) متغیر است؛ عدد پیش‌فرض ۰ است.

برای مبتدیان: اگر می‌خواهید یک کار سنگین (مثل فشرده‌سازی یک فایل بزرگ) در پس‌زمینه اجرا شود بدون این‌که کل سیستم را کند کند، از `nice` استفاده کنید.

# Syntax

```
nice [-n ADJUSTMENT] COMMAND [ARGS...]
```

# Options

| گزینه | توضیح |
|-------|--------|
| `-n N` | مقدار افزایش nice (عدد بزرگ‌تر = اولویت کمتر) |

# Examples

```bash
# اجرای یک فشرده‌سازی با اولویت پایین (مزاحم کارهای دیگر نمی‌شود)
nice -n 19 tar -czf backup.tar.gz /data

# اجرا با اولویت کمی پایین‌تر از پیش‌فرض
nice -n 10 ./heavy_script.sh

# اولویت بالاتر (نیاز به sudo دارد)
sudo nice -n -5 ./important_task.sh

# دیدن مقدار nice پردازش‌های در حال اجرا
ps -eo pid,ni,comm
```

# Common mistakes

- تصور اینکه عدد nice منفی به معنای «اولویت منفی/بد» است؛ در واقع عدد منفی یعنی اولویت بالاتر (سریع‌تر اجرا می‌شود).
- تلاش برای دادن اولویت بالاتر (عدد منفی) بدون `sudo` که با خطای permission مواجه می‌شود.

# Tips

- برای کارهای پس‌زمینه‌ای که نباید سیستم را کند کنند (مثل بکاپ‌گیری خودکار)، همیشه `nice -n 19` مناسب است.
- برای تغییر اولویت پردازشی که از قبل در حال اجراست، از `renice` استفاده کنید نه `nice`.

# Related commands

- `renice` — تغییر اولویت پردازش در حال اجرا
- `ionice` — تنظیم اولویت I/O دیسک
- `top` / `htop` — مشاهده اولویت پردازش‌ها
