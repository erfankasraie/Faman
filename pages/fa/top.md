# Introduction

`top` فرایندها را به‌صورت زنده و به‌روز نشان می‌دهد و مصرف CPU و حافظه را نمایش می‌دهد. ابزار کلاسیک مانیتورینگ ترمینال است.

# Syntax

```
top [OPTIONS]
```

# Options

| گزینه | توضیح |
|-------|--------|
| `-d SEC` | فاصله به‌روزرسانی (ثانیه) |
| `-p PID` | فقط چند PID خاص |
| `-u USER` | فقط یک کاربر |
| `-b` | حالت batch (برای لاگ) |
| `-n N` | تعداد تکرار به‌روزرسانی |

# Examples

```bash
# مانیتور معمولی
top

# به‌روزرسانی هر ۲ ثانیه
top -d 2

# فقط یک کاربر
top -u www-data

# خروجی یک‌باره برای اسکریپت
top -b -n 1
```

داخل `top`:

- `q` — خروج
- `k` — کشتن فرایند (با وارد کردن PID)
- `M` — مرتب‌سازی بر اساس حافظه
- `P` — مرتب‌سازی بر اساس CPU
- `h` — راهنما

# Common mistakes

- ماندن طولانی در `top` بدون نیاز و مصرف منابع ترمینال.
- اشتباه گرفتن `%CPU` با مصرف واقعی یک هسته در سیستم‌های چند هسته‌ای.

# Tips

- بسیاری ترجیح می‌دهند `htop` را نصب کنند (رابط رنگی‌تر و راحت‌تر).
- برای خلاصه سریع: `top -b -n 1 | head -20`

# Related commands

- `htop` — نسخه تعاملی‌تر
- `ps` — لیست یک‌باره فرایندها
- `free` — وضعیت حافظه
- `vmstat` — آمار مجازی حافظه و IO
