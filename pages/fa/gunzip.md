# Introduction

`gunzip` فایل‌های فشرده‌شده با فرمت `.gz` را از حالت فشرده خارج می‌کند؛ معادل دقیق `gzip -d`.

# Syntax

```
gunzip [OPTIONS] FILE.gz
```

# Options

| گزینه | توضیح |
|-------|--------|
| `-k` | نگه‌داشتن فایل `.gz` اصلی بعد از استخراج (پیش‌فرض حذف می‌شود) |
| `-c` | خروجی به stdout به‌جای ساخت فایل (بدون تغییر فایل اصلی) |
| `-v` | نمایش جزئیات و درصد فشرده‌سازی |
| `-l` | نمایش اطلاعات فایل فشرده بدون استخراج آن |

# Examples

```bash
# استخراج ساده (فایل .gz اصلی حذف می‌شود)
gunzip file.txt.gz

# استخراج با نگه‌داشتن فایل فشرده اصلی
gunzip -k file.txt.gz

# مشاهده محتوا بدون استخراج فیزیکی (خروجی به stdout)
gunzip -c file.txt.gz | head

# استخراج چند فایل همزمان
gunzip *.gz

# دیدن اطلاعات فایل فشرده (اندازه اصلی و فشرده) بدون استخراج
gunzip -l file.txt.gz
```

# Common mistakes

- فراموش‌کردن این‌که `gunzip` به‌صورت پیش‌فرض فایل `.gz` اصلی را **حذف** می‌کند بعد از استخراج؛ اگر می‌خواهید نسخه فشرده را هم نگه دارید، از `-k` استفاده کنید.
- تلاش برای استخراج یک آرشیو `.tar.gz` فقط با `gunzip`؛ این کار فقط لایه gzip را باز می‌کند و یک فایل `.tar` باقی می‌ماند که باید جداگانه با `tar` استخراج شود (یا مستقیماً از `tar -xzf` استفاده کنید).

# Tips

- برای فایل‌های `.tar.gz`، معمولاً نیازی به `gunzip` جداگانه نیست؛ `tar -xzf file.tar.gz` هر دو مرحله (باز‌کردن gzip و استخراج tar) را یک‌جا انجام می‌دهد.
- `gunzip -c` (بدون تغییر فایل روی دیسک) برای پیش‌نمایش سریع محتوای یک فایل لاگ فشرده بدون استخراج کامل آن مفید است.

# Related commands

- `gzip` — فشرده‌سازی فایل (عکس gunzip)
- `tar` — بایگانی و استخراج (اغلب همراه با gzip: `.tar.gz`)
- `zcat` — نمایش محتوای فایل gz بدون استخراج (معادل gunzip -c)
- `xz` / `zstd` — فرمت‌های فشرده‌سازی جایگزین با نسبت فشرده‌سازی بهتر
