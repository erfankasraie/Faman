# Introduction

`clear` صفحه ترمینال را پاک می‌کند تا خروجی قبلی دیده نشود.

# Syntax

```
clear
```

# Options

معمولاً بدون گزینه استفاده می‌شود. در بعضی سیستم‌ها `clear -x` اسکرول‌بک را نگه می‌دارد.

# Examples

```bash
clear
# میانبر رایج در بسیاری ترمینال‌ها: Ctrl+L
```

# Common mistakes

- فکر کردن که clear تاریخچه دستورات را پاک می‌کند — فقط نمایش را پاک می‌کند.

# Tips

- `reset` ترمینال را کامل‌تر بازنشانی می‌کند اگر خراب شده باشد.

# Related commands

- `reset` — بازنشانی ترمینال
- `history -c` — پاک کردن تاریخچه (bash)
