# Introduction

`seq` یک دنباله از اعداد را چاپ می‌کند؛ معمولاً برای ساخت حلقه‌های شماره‌دار در اسکریپت‌های شل یا تولید لیست اعداد استفاده می‌شود.

# Syntax

```
seq [OPTIONS] LAST
seq [OPTIONS] FIRST LAST
seq [OPTIONS] FIRST STEP LAST
```

# Options

| گزینه | توضیح |
|-------|--------|
| `-s SEP` | جداکننده بین اعداد به‌جای خط جدید |
| `-w` | تراز‌کردن عرض اعداد با صفر ابتدایی |
| `-f FORMAT` | قالب‌بندی سفارشی هر عدد |

# Examples

```bash
# اعداد ۱ تا ۵
seq 5

# اعداد ۱۰ تا ۲۰
seq 10 20

# اعداد ۰ تا ۱۰۰ با گام ۱۰
seq 0 10 100

# استفاده در حلقه bash
for i in $(seq 1 5); do
  echo "تکرار شماره $i"
done

# اعداد با صفر ابتدایی برای نام فایل مرتب (001, 002, ...)
seq -w 1 10

# جداکننده کاما به‌جای خط جدید
seq -s ',' 1 5
# → 1,2,3,4,5
```

# Common mistakes

- استفاده از `seq` برای حلقه در bash به‌جای روش داخلی `{1..5}` یا `for ((i=1;i<=5;i++))`؛ این روش‌های داخلی سریع‌تر و بدون فراخوانی فرایند خارجی هستند، اما `seq` وقتی گام (step) یا قالب خاص نیاز دارید (که `{1..5}` پشتیبانی نمی‌کند) ضروری‌تر است.
- فراموش‌کردن `-w` هنگام نیاز به مرتب‌سازی الفبایی صحیح فایل‌های شماره‌دار (بدون آن، `9` بعد از `10` می‌آید در مرتب‌سازی متنی).

# Tips

- برای حلقه‌های ساده در bash، `{1..5}` (براکت‌گذاری bash) معمولاً ترجیح داده می‌شود چون نیاز به فرایند خارجی ندارد؛ `seq` را برای گام‌های غیر ۱ یا قالب‌بندی خاص نگه دارید.
- `seq -w` برای ساخت نام فایل‌های مرتب مثل `file001.txt` تا `file100.txt` بسیار کاربردی است.

# Related commands

- `for` (bash builtin با `{1..N}`) — جایگزین داخلی سریع‌تر برای حلقه‌های ساده
- `shuf` — تولید اعداد تصادفی (نه مرتب)
- `printf` — قالب‌بندی دقیق‌تر اعداد
