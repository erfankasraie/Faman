# Introduction

`join` دو فایل متنی مرتب‌شده را بر اساس یک فیلد مشترک ترکیب می‌کند؛ دقیقاً مثل عملیات `JOIN` در پایگاه‌داده SQL اما روی فایل‌های متنی.

# Syntax

```
join [OPTIONS] FILE1 FILE2
```

# Options

| گزینه | توضیح |
|-------|--------|
| `-1 N` | شماره فیلد اتصال در فایل اول |
| `-2 N` | شماره فیلد اتصال در فایل دوم |
| `-t CHAR` | جداکننده فیلدها (پیش‌فرض: فاصله) |
| `-a N` | نمایش خطوط بدون تطابق از فایل N هم (مثل LEFT/RIGHT JOIN) |
| `-e VAL` | مقدار جایگزین برای فیلدهای خالی |

# Examples

```bash
# هر دو فایل باید ابتدا بر اساس فیلد اتصال مرتب شوند
sort file1.txt -o file1.txt
sort file2.txt -o file2.txt

# ترکیب ساده بر اساس ستون اول هر دو فایل
join file1.txt file2.txt

# اتصال با جداکننده کاما و فیلد دوم از فایل دوم
join -t ',' -1 1 -2 2 users.csv orders.csv

# نمایش خطوط بدون تطابق از فایل اول هم (شبیه LEFT JOIN)
join -a 1 file1.txt file2.txt
```

# Common mistakes

- فراموش‌کردن مرتب‌سازی (sort) قبل از join؛ اگر فایل‌ها مرتب نباشند نتیجه ناقص یا اشتباه خواهد بود.
- فرض‌کردن فیلد اتصال همیشه ستون اول است؛ باید با `-1` و `-2` مشخص شود اگر غیر از این باشد.

# Tips

- برای کارهای پیچیده‌تر شبیه SQL روی فایل‌های متنی، `join` را با `awk` یا `sort -k` ترکیب کنید.
- اگر داده‌ها CSV واقعی با فیلدهای دارای کاما داخل مقادیر هستند، بهتر است از ابزار مخصوص CSV یا `csvkit` استفاده شود.

# Related commands

- `paste` — ترکیب ستونی ساده بدون نیاز به فیلد مشترک
- `sort` — مرتب‌سازی پیش‌نیاز join
- `comm` — مقایسه دو فایل مرتب‌شده
- `awk` — پردازش پیشرفته‌تر متن
