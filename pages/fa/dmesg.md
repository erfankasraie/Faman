# Introduction

دستور `dmesg` (مخفف display message) پیام‌های بافر حلقه‌ای کرنل (kernel ring buffer) را نمایش می‌دهد. این پیام‌ها شامل اطلاعات مربوط به بوت شدن سیستم، شناسایی سخت‌افزار، درایورها و خطاهای سطح کرنل است.

برای مبتدیان: وقتی یک دستگاه USB وصل می‌کنید یا سیستم دچار مشکل سخت‌افزاری می‌شود، `dmesg` اولین جایی است که باید نگاه کنید.

# Syntax

```
dmesg [OPTIONS]
```

# Options

| گزینه | توضیح |
|-------|--------|
| `-H` | نمایش خوانا و صفحه‌بندی‌شده (human-readable) با رنگ |
| `-T` | نمایش زمان به‌صورت تاریخ واقعی به‌جای ثانیه از بوت |
| `-w` | حالت follow؛ پیام‌های جدید را زنده نشان می‌دهد |
| `-l LEVEL` | فیلتر بر اساس سطح (err، warn، info، ...) |
| `-c` | نمایش و سپس پاک‌کردن بافر |
| `--color` | رنگی‌کردن خروجی |

# Examples

```bash
# نمایش کامل پیام‌های کرنل با زمان واقعی
dmesg -T

# فقط خطاها را نشان بده
dmesg -l err

# دنبال‌کردن پیام‌های جدید (مثلاً هنگام وصل‌کردن USB)
dmesg -w

# جستجوی مشکلات مربوط به دیسک
dmesg | grep -i error
```

# Common mistakes

- اجرا بدون دسترسی کافی و دریافت پیام «permission denied» در برخی توزیع‌ها؛ در این حالت از `sudo dmesg` استفاده کنید.
- فراموش‌کردن `-T` و گیج‌شدن با زمان‌های عجیب (که در واقع ثانیه از لحظه بوت هستند).

# Tips

- ترکیب `dmesg -w` با وصل‌کردن دستگاه USB روش سریعی برای دیدن نام دیوایس (مثلاً `/dev/sdb`) است.
- برای بررسی مشکلات حافظه یا OOM Killer: `dmesg | grep -i "out of memory"`

# Related commands

- `journalctl` — لاگ‌های کامل سیستم‌دی (شامل dmesg)
- `lsblk` — لیست دیسک‌ها و پارتیشن‌ها
- `uname` — اطلاعات کرنل و سیستم
