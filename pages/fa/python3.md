# Introduction

`python3` مفسر زبان برنامه‌نویسی Python است؛ برای اجرای اسکریپت‌ها، محاسبات سریع، و به‌عنوان یک ماشین‌حساب/محیط تعاملی قدرتمند در ترمینال استفاده می‌شود.

# Syntax

```
python3 [OPTIONS] [SCRIPT.py] [ARGUMENTS]
```

# Options

| گزینه | توضیح |
|-------|--------|
| `-c CODE` | اجرای مستقیم یک قطعه کد |
| `-m MODULE` | اجرای یک ماژول به‌عنوان اسکریپت (مثل `-m http.server`) |
| `-i` | ورود به حالت تعاملی پس از اجرای اسکریپت |
| `-V` | نمایش نسخه پایتون |
| `-u` | خروجی بدون بافرینگ (مفید برای لاگ‌های زنده) |

# Examples

```bash
# اجرای یک اسکریپت
python3 script.py

# اجرای مستقیم یک خط کد
python3 -c "print(2**10)"

# ورود به محیط تعاملی (REPL)
python3

# راه‌اندازی سریع یک وب‌سرور ساده برای اشتراک فایل در پوشه جاری
python3 -m http.server 8000

# اجرای یک ماژول نصب‌شده به‌عنوان برنامه
python3 -m venv myenv

# اجرای اسکریپت با آرگومان‌های ورودی
python3 script.py arg1 arg2
```

# Common mistakes

- استفاده از `python` به‌جای `python3` در سیستم‌هایی که `python` به Python 2 اشاره می‌کند یا اصلاً وجود ندارد؛ در توزیع‌های مدرن معمولاً فقط `python3` موجود است.
- نصب پکیج‌ها با `pip` به‌صورت سراسری (global) به‌جای استفاده از محیط مجازی (`venv`) که می‌تواند باعث تداخل نسخه‌ها بین پروژه‌های مختلف شود.
- فراموش‌کردن فعال‌سازی محیط مجازی قبل از اجرای اسکریپت یا نصب پکیج.

# Tips

- برای هر پروژه جدید، یک محیط مجازی جداگانه بسازید: `python3 -m venv .venv && source .venv/bin/activate`
- `python3 -m http.server` روش سریعی برای اشتراک‌گذاری فایل‌های یک پوشه در شبکه محلی بدون نصب هیچ نرم‌افزار اضافه‌ای است.

# Related commands

- `pip` — نصب و مدیریت پکیج‌های پایتون
- `venv` / `virtualenv` — ساخت محیط مجازی ایزوله
- `pyenv` — مدیریت چند نسخه پایتون روی یک سیستم
