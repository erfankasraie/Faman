# Introduction

`umask` مجوز پیش‌فرضی که فایل‌ها و پوشه‌های **جدید** با آن ساخته می‌شوند را کنترل می‌کند؛ برخلاف `chmod` که مجوز یک فایل موجود را تغییر می‌دهد، `umask` روی فایل‌هایی که *از این پس* ساخته می‌شوند اثر می‌گذارد.

برای مبتدیان: umask یک عدد را از حداکثر مجوز ممکن (۶۶۶ برای فایل، ۷۷۷ برای پوشه) کم می‌کند تا مجوز نهایی پیش‌فرض به‌دست بیاید.

# Syntax

```
umask [MODE]
```

# Options

بدون آرگومان، umask فعلی را نمایش می‌دهد. با یک عدد اکتال (مثل `022`)، umask جدید را تنظیم می‌کند (فقط برای نشست جاری، مگر در فایل تنظیمات شل ذخیره شود).

# Examples

```bash
# نمایش umask فعلی
umask
# → 0022

# تنظیم umask محدودتر (فایل‌های جدید فقط برای خود کاربر خواندنی/نوشتنی)
umask 077

# محاسبه مجوز نهایی: ۶۶۶ (فایل) منهای umask
# umask 022 → فایل جدید: 644 (rw-r--r--)
# umask 077 → فایل جدید: 600 (rw-------)

# بررسی مجوز پیش‌فرض با ساخت یک فایل تست
umask 022
touch test1.txt
ls -l test1.txt   # -rw-r--r--

umask 077
touch test2.txt
ls -l test2.txt   # -rw-------

# تنظیم دائمی در فایل تنظیمات شل
echo "umask 022" >> ~/.bashrc
```

# Common mistakes

- گیج‌شدن بین umask (مجوز پیش‌فرض فایل‌های *جدید*) و chmod (تغییر مجوز فایل *موجود*)؛ تغییر umask هیچ اثری روی فایل‌های از‌قبل‌ساخته‌شده ندارد.
- فراموش‌کردن این‌که umask برای پوشه‌ها متفاوت از فایل‌هاست: پوشه از ۷۷۷ کم می‌شود، فایل از ۶۶۶ (فایل‌های عادی به‌صورت پیش‌فرض بدون مجوز اجرا ساخته می‌شوند).
- تنظیم umask بسیار محدود (مثل `077`) روی یک سرور اشتراکی بدون بررسی این‌که آیا سرویس‌های دیگر به فایل‌های جدید دسترسی نیاز دارند یا نه.

# Tips

- برای سرورهایی که امنیت بالا نیاز دارند (مثلاً فایل‌های حساس کاربر)، `umask 077` تضمین می‌کند فایل‌های جدید فقط برای خود کاربر قابل‌دسترسی باشند.
- umask پیش‌فرض اکثر توزیع‌ها `022` است که یعنی فایل‌های جدید همه‌کاربران می‌توانند بخوانند ولی فقط مالک می‌تواند بنویسد.

# Related commands

- `chmod` — تغییر مجوز فایل موجود
- `chown` — تغییر مالکیت فایل
- `stat` — نمایش مجوز و اطلاعات دقیق فایل
