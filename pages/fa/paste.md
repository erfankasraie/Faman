# Introduction

`paste` خطوط چند فایل را به‌صورت ستونی (کنار هم) با هم ترکیب می‌کند؛ برخلاف `cat` که فایل‌ها را زیر هم می‌چسباند.

# Syntax

```
paste [OPTIONS] FILE...
```

# Options

| گزینه | توضیح |
|-------|--------|
| `-d SEP` | تعیین جداکننده به‌جای تب پیش‌فرض |
| `-s` | ترکیب خطوط یک فایل در یک خط (سری‌ای) |

# Examples

```bash
# ترکیب دو فایل ستون به ستون (با تب)
paste names.txt scores.txt

# استفاده از کاما به‌جای تب
paste -d ',' names.txt scores.txt

# تبدیل تمام خطوط یک فایل به یک خط با کاما
paste -s -d ',' list.txt

# ترکیب خروجی چند دستور
paste <(ls dir1) <(ls dir2)
```

# Common mistakes

- انتظار داشتن جداکننده کاما به‌صورت پیش‌فرض؛ پیش‌فرض واقعی تب (`\t`) است.
- فایل‌هایی با تعداد خط متفاوت که باعث می‌شود ستون‌های کوتاه‌تر خالی نمایش داده شوند.

# Tips

- ترکیب `paste -s -d ','` روش سریعی برای تبدیل یک فایل تک‌ستونی به لیست جدا‌شده با کاما (CSV تک‌خطی) است.
- برای ترکیب برعکس (شکستن ستون‌ها به خط) از `tr` یا `column` استفاده کنید.

# Related commands

- `join` — ترکیب دو فایل بر اساس یک فیلد مشترک
- `cut` — استخراج ستون‌ها از یک فایل
- `column` — نمایش جدولی متن
