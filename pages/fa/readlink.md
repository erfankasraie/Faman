# Introduction

`readlink` مسیر واقعی که یک لینک نمادین (symbolic link) به آن اشاره می‌کند را نشان می‌دهد، یا با گزینه `-f` مسیر مطلق و کاملاً حل‌شده (resolved) یک فایل را برمی‌گرداند حتی اگر لینک نباشد.

# Syntax

```
readlink [OPTIONS] FILE
```

# Options

| گزینه | توضیح |
|-------|--------|
| `-f` | حل کامل مسیر (تمام لینک‌ها و `..`) به مسیر مطلق نهایی |
| `-e` | مثل `-f` ولی اگر مسیر نهایی وجود نداشته باشد خطا می‌دهد |
| `-m` | مثل `-f` ولی نیازی به وجود داشتن مسیر نیست |

# Examples

```bash
# دیدن این‌که یک لینک به کجا اشاره می‌کند
readlink /usr/bin/python3

# گرفتن مسیر مطلق کامل یک فایل (حتی نسبی یا با لینک)
readlink -f ./script.sh

# استفاده در اسکریپت برای پیداکردن مسیر خود اسکریپت
SCRIPT_DIR=$(dirname "$(readlink -f "$0")")

# بررسی این‌که مسیر نهایی واقعاً وجود دارد
readlink -e /etc/some-config
```

# Common mistakes

- استفاده از `readlink` بدون `-f` روی فایلی که لینک نیست؛ در این حالت خروجی خالی برمی‌گردد (چون فایل، لینک نمادین نیست).
- اشتباه‌گرفتن با `realpath`؛ `realpath` مشابه `readlink -f` عمل می‌کند اما به‌صورت اختصاصی برای این کار ساخته شده و در برخی سیستم‌ها موجودتر است.

# Tips

- الگوی `SCRIPT_DIR=$(dirname "$(readlink -f "$0")")` یکی از پرکاربردترین الگوها در اسکریپت‌نویسی بش برای پیداکردن مسیر واقعی اسکریپت در حال اجراست.
- برای اکثر کاربردهای روزمره، `realpath` ساده‌تر و خواناتر است.

# Related commands

- `realpath` — گرفتن مسیر مطلق و حل‌شده یک فایل
- `ln` — ساخت لینک نمادین یا سخت
- `basename` / `dirname` — استخراج نام فایل یا پوشه از مسیر
