# Introduction

`who` لیست تمام کاربرانی که در حال حاضر به سیستم login کرده‌اند را نمایش می‌دهد؛ همراه با اینکه از کدام ترمینال و از چه زمانی وارد شده‌اند. برای سرورهای اشتراکی (چند کاربره) بسیار کاربردی است.

# Syntax

```
who [OPTIONS]
```

# Options

| گزینه | توضیح |
|-------|--------|
| `-a` | نمایش تمام اطلاعات ممکن |
| `-b` | زمان آخرین بوت سیستم |
| `-q` | فقط تعداد و نام کاربران (خلاصه) |
| `-H` | نمایش با هدر ستون‌ها |

# Examples

```bash
# نمایش کاربران فعلاً login شده
who

# نمایش با هدر برای خوانایی بیشتر
who -H

# نمایش خلاصه (فقط نام‌ها و تعداد)
who -q

# دیدن زمان آخرین بوت سیستم
who -b

# بررسی این‌که آیا کاربر خاصی الان login است
who | grep ali
```

# Common mistakes

- گیج‌شدن `who` (کاربران login شده در سیستم) با `whoami` (فقط نام کاربری خودتان در نشست جاری).
- انتظار داشتن اطلاعات از کاربرانی که از طریق SSH با کلید بدون shell interactive وصل شده‌اند (مثل بعضی ابزارهای اتوماسیون)؛ ممکن است در خروجی `who` دیده نشوند چون نشست شل واقعی باز نکرده‌اند.

# Tips

- برای اطلاعات کامل‌تر شامل «کاربر الان چه کاری انجام می‌دهد»، `w` جایگزین بهتری است.
- روی سرورهای production، بررسی دوره‌ای `who` می‌تواند کمک کند بفهمید چه کسانی همزمان روی سرور هستند قبل از انجام تغییرات حساس.

# Related commands

- `whoami` — فقط نام کاربری خودتان
- `w` — کاربران login شده به‌همراه فعالیت فعلی
- `last` — تاریخچه login های قبلی (نه فقط فعلی)
