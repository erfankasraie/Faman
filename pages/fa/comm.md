# Introduction

`comm` دو فایل **مرتب‌شده** را خط‌به‌خط مقایسه می‌کند و در سه ستون نشان می‌دهد: خطوط فقط در فایل اول، خطوط فقط در فایل دوم، و خطوط مشترک بین هر دو.

# Syntax

```
comm [OPTIONS] FILE1 FILE2
```

# Options

| گزینه | توضیح |
|-------|--------|
| `-1` | مخفی‌کردن ستون «فقط در فایل اول» |
| `-2` | مخفی‌کردن ستون «فقط در فایل دوم» |
| `-3` | مخفی‌کردن ستون «مشترک» |
| `-i` | نادیده‌گرفتن بزرگی/کوچکی حروف |

# Examples

```bash
# مقایسه کامل با سه ستون
comm file1.txt file2.txt

# نمایش فقط خطوط مشترک بین دو فایل
comm -12 file1.txt file2.txt

# نمایش فقط خطوطی که در فایل اول هستند ولی در دوم نیستند
comm -23 file1.txt file2.txt

# نمایش فقط خطوطی که در فایل دوم هستند ولی در اول نیستند
comm -13 file1.txt file2.txt
```

# Common mistakes

- فراموش‌کردن مرتب‌سازی قبل از اجرا؛ `comm` روی فایل‌های نامرتب نتیجه درستی نمی‌دهد (باید ابتدا `sort` اجرا شود).
- اشتباه‌گرفتن `comm` با `diff`؛ `diff` برای مقایسه تغییرات خط‌به‌خط با ترتیب اصلی مناسب‌تر است، `comm` برای مقایسه مجموعه‌ای (set) از خطوط.

# Tips

- ترکیب `comm -12 <(sort f1) <(sort f2)` (با process substitution) نیازی به ساخت فایل موقت مرتب‌شده ندارد.
- برای پیداکردن سریع تفاوت دو لیست کاربر یا نام دامنه، `comm` بسیار سریع‌تر از نوشتن اسکریپت است.

# Related commands

- `diff` — مقایسه دقیق خط‌به‌خط با ترتیب
- `sort` — پیش‌نیاز اجرای comm
- `uniq` — حذف خطوط تکراری
- `join` — ترکیب دو فایل بر اساس فیلد مشترک
