نقشه راه توسعه **faman**.

## v0.1 — Static Pages ✅

CLI پایه، پارسر Markdown، رندر رنگی، جستجو، ده‌ها صفحه فارسی، تست و CI.

## v0.1.x — رشد محتوا (در حال انجام)

- صفحات بیشتر (process، network، package managers)
- یکنواختی ساختار صفحات
- اسکرین‌شات واقعی

## v0.2 — Interactive TUI

رابط تمام‌صفحه‌ای با bubbletea، مرور دسته، جستجوی زنده، تاریخچه.

## v0.3 — Plugin System

صفحات سفارشی، چندزبانه، هوک‌ها.

## v0.4 — Online Updates

دانلود امن صفحات از مخزن رسمی + کش محلی.

## v0.5 — AI Assistant

پاسخ به سؤال آزاد، تولید مثال، توضیح خطا.

## v1.0 — Stable

پوشش گسترده، بسته‌بندی توزیع‌ها، پایداری فرمت صفحات.
